# 敌人状态机

> 依据代码：EnemyLogic（持有索敌结果 / 丢目标计时 / 攻击冷却）、EnemyMoveGroup（3 态切换）、EnemyAttackState（前摇 / 冲刺 / 后摇 3 阶段）。
> 探测与贴地看 EnemyMotor 与预制体上的 DetectCollider；数值全在 `Assets/Resources/Data/EnemyConfig.asset`。
> 三个状态只描述「自己怎么动」，「什么时候被换掉」只在 EnemyMoveGroup 里判定。

## 一、每物理帧顺序

1. 采样世界：EnemyMotor 以 `View/Bottom` 为脚底基准探地面（踩地时贴回并清零 vy）、探墙、探朝向那一侧的悬崖，组装 WorldInfo。
2. BeginStep：读真值、清增量、外部速度衰减一次。
3. 写入本帧索敌结果（DetectCollider 的进 / 出事件维护的可见性与玩家位置）与巡逻范围（PatrolCollider 的 x 边界）。
4. 更新丢目标计时：看得见清零并记下位置，看不见累加 Δt。
5. EnemyMoveGroup：先判抢占，再判当前状态是否结束，最后才 Tick 状态本身。
6. 当前状态 Tick：提交横向速度指令。
7. ApplyGravity → Commit。

## 二、切态判定

切态只有两条路，都在 EnemyMoveGroup 里：

| 机制 | 条件 | 下一态 |
| --- | --- | --- |
| 抢占 | 巡逻中 · 玩家在探测范围内 | 追踪 |
| 抢占 | 追踪中 · 玩家在探测范围内 · 冷却已好 | 攻击 |
| Fallback | 追踪结束（丢目标超时） | 巡逻 |
| Fallback | 攻击结束 · 仍有警戒 | 追踪 |
| Fallback | 攻击结束 · 丢目标超时 | 巡逻 |
| Fallback | 首帧（无当前状态） | 巡逻 |

- 「仍有警戒」= 看得见，或看不见但未超过 `loseTargetTime`。
- 抢占先于结束判定：同残帧里能抢就抢，抢不到才看 `IsDone`。
- **攻击态不被抢占**：起手后一定走完前摇 + 冲刺 + 后摇，中途丢目标只影响下一轮；后摇结束若能立刻再来一刀，由 EnemyAttackState 内部重进前摇（同状态再切会被幂等挡掉）。
- 抢占要求「玩家在探测范围内」而不只是「仍有警戒」：玩家出了范围只剩追赶，不该再起手。

## 三、巡逻

- 只在踩地时推进，离地一律刹车（坠落、被顶飞时不会在空中左右飘）。
- 范围：预制体上有 `PatrolCollider` 就在它的世界 x 范围内来回走；没有这个子物体、或者怪物已经跑出触发器（被击退顶飞），就按**整平台**算。
- 边界在装配时快照一次：子物体形态的触发器跟着怪物走，每帧实时读会永远等于当前位置，等于没有边界。
- 方向：到边界、贴墙、前方是悬崖，三者任一就掉头。
- 没有「以出生点为中心 ± 半径」这一说：出生点只在它恰好站在触发器中心时才等价。

## 四、追踪

- 朝玩家的水平方向走，速度用 `moveSpeed`。
- 水平距离 ≤ `chaseStopDistance` 就刹车等冷却，否则会把玩家一路顶走。
- 玩家在悬崖对面就停在崖边（`LedgeAhead`），不会为了追人跳下去。
- 玩家刚离开探测范围时仍朝最后已知位置走；丢目标超时才回巡逻。

## 五、攻击

- 阶段：Windup → Dash → Recovery，阶段与计时都在 EnemyAttackState 内部。
- 前摇：原地刹车，期间仍跟着玩家转身；结束那一帧锁定冲刺方向（水平，取玩家所在侧），之后玩家跑开也照原方向冲。
- 冲刺：按锁定方向以 `attackDashSpeed` 平移；横向速度每帧重写，贴地与碰撞都会改写速度，写一次守不住整段。
- 冲刺不出平台：脚下前方一空（`LedgeAhead`）就当场转后摇，锁定方向正对悬崖也不会冲出去。
- 后摇：横向速度当场清零，原地刹车。
- 后摇结束：冷却已好且玩家仍在探测范围内 → 原地重新进前摇；否则交给追踪 / 巡逻。
- 冷却比整套动作短时，后摇一结束就接下一次；比它长时，剩下的时间在追踪态里等。

## 六、丢目标与冷却的单一来源

- 丢目标计时、攻击冷却都只在 EnemyLogic 里维护，状态与状态组都只读，不要各自再存一份。
- 巡逻范围是表现层每帧喂进来的 `EnemyPatrolArea`（无界 = 整平台），状态只读，不要自己记边界。

## 七、站桩（EnemyController.OpenAI = false）

- `EnemyMoveGroup` 整个不推进：不进任何状态、不巡逻不追不打，出生就待在原地。
- 每帧仍要 `BrakeTowardsX`：刚体没有线性阻尼，被玩家撞一下会一直滑，站桩必须自己刹住。
- 受击照常：`TakeDamage` 仍然进 `ConditionGroup`，受伤态、无敌窗、击退都按常规走。
- 伤害值恒为 0：进 `TryApply` 前把 `Damage.Amount` 抹成 0，于是不扣血、不进无敌窗（0 伤害本就是「纯效果」语义），血永远满着，也就永远走不到销毁。
- 只是「打不死」，不是「打不中」：命中判定、受击表现、击退位移都还在，方便当靶子练连段。

## 八、预制体接线（Enemy.prefab）

- 根节点：Rigidbody2D + EnemyMotor + EnemyController；两个组件的 config 指到同一份 EnemyConfig。
- 子物体按名字找，不在 Inspector 里连线：View（显示）、BodyCollider（身体，非触发器）、DetectCollider（触发器，索敌范围）、PatrolCollider（可选，巡逻范围）。
- `PatrolCollider` 若存在，取它的世界 x 范围当巡逻边界（装配时快照）；它同时是「怪物还在范围内吗」的判定盒，所以要把它做得能装下整条巡逻路线。
- `View` 下必须有 `Bottom` 与 `Top` 两个空物体：脚底探测、贴地、悬崖探针都以 Bottom 为基准；缺了就退回碰撞体底边（贴地会有偏差）。
- `BodyCollider` 上挂 HurtBox、攻击盒上挂 AttackBox，两者由 EnemyController 在 Attach 里接上自己（一个挨打、一个出伤害）。
- EnemyDetectZone 由 EnemyController 在 Awake 里补挂到 DetectCollider 上，不用手工添加。
- 刚体参数由 EnemyMotor 在 Awake 里强制：Dynamic、gravityScale = 0、冻结旋转、插值。重力只有逻辑账本那一套。

## 九、尚未实现

- 冲刺不额外结算伤害：撞到玩家走的是 AttackCollider 的接触伤害（`contactDamage` / `contactKnockback`）。
- 死亡没有演出：血被打空直接 `Destroy` 整只，没有倒地 / 消散。
- 巡逻范围只认「敌人自己的子物体」形态的 PatrolCollider；放到关卡里当静态区域的话，还得再加一层场景查找。
