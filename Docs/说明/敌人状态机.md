# 敌人状态机

> 依据代码：EnemyLogic（持有索敌结果 / 丢目标计时 / 接触伤害间隔）、EnemyMoveGroup（2 态切换）、EnemyPatrolState / EnemyChaseState。
> 探测与贴地看 EnemyMotor 与预制体上的 DetectCollider；数值全在 `Assets/Resources/Data/EnemyConfig.asset`。
> 敌人不主动攻击：伤害只有贴身接触（AttackBox + `contactDamage` / `contactInterval`），没有独立的攻击状态。

## 一、每物理帧顺序

1. 采样世界：EnemyMotor 以 `View/Bottom` 为脚底基准探地面（踩地时贴回并清零 vy）、探墙、探朝向那一侧的悬崖，组装 WorldInfo。
2. BeginStep：读真值、清增量、外部速度衰减一次。
3. 写入本帧索敌结果（DetectCollider 的进 / 出事件维护的可见性与玩家位置）与巡逻范围（`Start` 里快照下来的世界 x 边界）。
4. 更新丢目标计时：看得见清零并记下位置，看不见累加 Δt。
5. EnemyMoveGroup：先判抢占，再判当前状态是否结束，最后才 Tick 状态本身。
6. 当前状态 Tick：提交横向速度指令。
7. ApplyGravity → Commit。

接触伤害不在这条链上，它由物理回调在物理步内触发（见第五节）。

## 二、切态判定

切态只有两条路，都在 EnemyMoveGroup 里：

| 机制 | 条件 | 下一态 |
| --- | --- | --- |
| 抢占 | 巡逻中 · 玩家在探测范围内 | 追踪 |
| Fallback | 追踪结束（丢目标超时） | 巡逻 |
| Fallback | 首帧（无当前状态） | 巡逻 |

- 「丢目标超时」= 看不见玩家且超过 `loseTargetTime`，判定在 EnemyChaseState.IsDone，去处由 Fallback 决定。
- 抢占先于结束判定：同残帧里能抢就抢，抢不到才看 `IsDone`。
- 追踪没有主动结束点：只要还在警戒内就一路贴上去，玩家跑多远跟多远（崖边除外）。

## 三、巡逻

- 只在踩地时推进，离地一律刹车（坠落、被顶飞时不会在空中左右飘）。
- 范围：`EnemyController` 上的 `patrolOffset` + `patrolSize` 画出的方框，取它的**世界 x 边界**当左右折返点。
- 参数是**局部坐标**（相对敌人）：编辑器里框跟着敌人一起显示，改摆位框自动跟着；运行时在 `Start` 里换算成世界坐标**快照一次**，之后敌人自己怎么走、被顶飞到哪，框都不动。
- `patrolSize` 两个分量留 0（默认）= 不启用巡逻框，走到墙或悬崖才掉头；给组件点 Reset 会铺一个 18×3 的框当起点。
- 方向：到边界、贴墙、前方是悬崖，三者任一就掉头。
- 没有「以出生点为中心 ± 半径」这一说：框的位置由 `patrolOffset` 决定，默认 0 就是以敌人出生点为中心。

## 四、追踪

- 一直朝玩家的水平方向走，速度用 `moveSpeed`，没有冷却也没有停顿。
- 贴上就停：水平距离 ≤ `chaseStopDistance` 刹车，再近会一路把玩家顶走。它与攻击盒半径的关系见第五节。
- 玩家在悬崖对面就停在崖边（`LedgeAhead`），不会为了追人跳下去。
- 玩家刚离开探测范围时仍朝最后已知位置走；丢目标超时才回巡逻。

## 五、接触伤害（持续掉血）

- 载体是子物体 `AttackCollider` 上的 `AttackBox`（CircleCollider2D，Is Trigger）+ 敌人的 `IAttacker.ProduceDamage`。
- **进入即咬一口，之后按 `contactInterval` 反复咬**：`AttackBox.OnTriggerStay2D` 每物理帧问攻击者 `IIntervalAttacker.ReadyToHit(now)`，到点才结算。只写 `OnTriggerEnter2D` 的话玩家站着不动就只能吃到第一口。
- 间隔在 `EnemyLogic._contactCooldown`（Foundation.Cooldown），**只在命中成功后 MarkHit**：被玩家无敌窗挡掉的那次不消耗间隔，无敌一结束就接着掉血。
- 间隔必须 ≥ 玩家的 `invulnerableTime`（当前 0.4s），否则多出来的那几次会被无敌窗吞掉，看起来像「隔很久才掉一次」。
- 子弹等一次性攻击盒不受影响：它们不实现 `IIntervalAttacker`，Stay 分支直接跳过，只有进入那一下结算。
- **敌人刚体强制 `NeverSleep`**：Stay 依赖物理回调，玩家站着不动、双方刚体都睡着时物理对不再回调，掉血会断。
- 伤害方向按几何现算（从攻击盒指向受击盒中心）：用攻击者朝向会把人往怀里推。
- 攻击盒半径 0.9 + 玩家半宽 0.45 ≈ 1.35 ≥ `chaseStopDistance`，所以贴住时判定一定成立；把 `chaseStopDistance` 调到 1.35 以上就成了「看得见摸不着」。
- 站桩（`OpenAI = false`）时这条链路照常，敌人仍然咬人，只是自己不动。

## 六、丢目标计时的单一来源

- 丢目标计时只在 EnemyLogic 里维护，状态与状态组都只读，不要各自再存一份。
- 巡逻范围是表现层每帧喂进来的 `EnemyPatrolArea`（无界 = 整平台），状态只读，不要自己记边界。

## 七、站桩（EnemyController.OpenAI = false）

- `EnemyMoveGroup` 整个不推进：不进任何状态、不巡逻不追，出生就待在原地。
- 每帧仍要 `BrakeTowardsX`：刚体没有线性阻尼，被玩家撞一下会一直滑，站桩必须自己刹住。
- 受击照常：`TakeDamage` 仍然进 `ConditionGroup`，受伤态、无敌窗、击退都按常规走。
- 伤害值恒为 0：进 `TryApply` 前把 `Damage.Amount` 抹成 0，于是不扣血、不进无敌窗（0 伤害本就是「纯效果」语义），血永远满着，也就永远走不到销毁。
- 只是「打不死」，不是「打不中」：命中判定、受击表现、击退位移都还在，方便当靶子练连段。

## 八、预制体接线（Enemy.prefab）

- 根节点：Rigidbody2D + EnemyMotor + EnemyController；两个组件的 config 指到同一份 EnemyConfig。
- 子物体按名字找，不在 Inspector 里连线：View（显示）、BodyCollider（身体，非触发器）、DetectCollider（触发器，索敌范围）、AttackCollider（触发器，接触伤害）。
- 巡逻范围不再是子物体：`EnemyController` 的 `patrolOffset` / `patrolSize` 给的是局部坐标，`OnDrawGizmosSelected` 里画淡绿线框（跟着敌人），选中即可在 Scene 视图里对着调。旧预制体上的 `PatrolCollider` 子物体现在完全不用了，留着也不影响。
- `View` 下必须有 `Bottom` 与 `Top` 两个空物体：脚底探测、贴地、悬崖探针都以 Bottom 为基准；缺了就退回碰撞体底边（贴地会有偏差）。
- `BodyCollider` 上挂 HurtBox、`AttackCollider` 上挂 AttackBox，两者由 EnemyController 在 Attach 里接上自己（一个挨打、一个出伤害）。
- EnemyDetectZone 由 EnemyController 在 Awake 里补挂到 DetectCollider 上，不用手工添加。
- 刚体参数由 EnemyMotor 在 Awake 里强制：Dynamic、gravityScale = 0、冻结旋转、插值、不休眠。重力只有逻辑账本那一套。

## 九、尚未实现

- 主动攻击：原来的前摇 / 冲刺 / 后摇三阶段已移除，敌人只靠贴身接触伤害（`contactDamage` / `contactInterval` / `contactKnockback`）。
- 死亡没有演出：血被打空直接 `Destroy` 整只，没有倒地 / 消散。
- 巡逻框只有矩形，没有平台形状：跨平台的巡逻要靠调高度把框放到对的位置，或者干脆用 `patrolSize.x ≤ 0` 交给墙与悬崖。
