# 玩家状态机

> 依据代码：MoveGroup（移动 6 态）、PostureGroup（姿态 3 态）、AttackGroup（攻击 4 态）。  
> 速度逼近看 MoveLedger，探测/贴地/身高看 MoveMotor。  
> 三套状态机正交：移动管速度与重力，姿态管身高、移速与动作禁令，攻击管开火与后坐力。  
> 每条按「时机 + 动作」写，一行一条。

## 一、每帧顺序

1. 采样世界：探地面、探墙，踩地时贴地吸附并清零 vy。
2. BeginStep：读真值并剥掉外部速度，清空增量，速度乘数复位，外部速度衰减一次。
3. 姿态机：定下本帧能否跳/冲、身高倍率与 View 目标值。
4. 移动机：先判抢占（冲刺优先于跳），再判状态是否结束。
5. 状态 Tick：提交本帧的水平逼近与重力设定。
6. 攻击机：排在移动机之后，开火那一帧生成子弹并叠加一份反向外部速度（后坐力）。
7. ApplyGravity：施加当前重力，钳制上升与下落速度。
8. Commit：有提交或外部速度在变才写回，写的是「常规速度 + 外部速度」。
9. 渲染帧：把姿态给的缩放落到 View，以脚底为锚点。

## 二、移动机的抢占与回落

- 抢占顺序固定：先判冲刺，再判跳跃（地面跳 / 空中跳）。
- 抢占必须成功消费对应输入，否则本次抢占作废。
- 目标与当前状态相同则不切换，直接继续 Tick。
- 当前状态 IsDone 后，按基础态规则回落。
- 基础态：离地且帧首 vy>0 → Jump，否则 → Fall。
- 基础态：踩地且有水平输入 → Move，否则 → Idle。
- 落地那一帧：清土狼消耗、空中跳次数、空中冲刺次数。

## 三、Idle 地面待机

- 进入：踩地且无水平输入（落地后或松键后）。
- 物理：每帧按 moveDeceleration 把 vx 收敛到 0。
- 物理：踩地且 vy≤0 时 vy 钳为 0，贴地不下沉。
- 退出：有水平输入 → Move；离地 → 按 vy 分 Jump / Fall。

## 四、Move 地面行走

- 进入：踩地且有水平输入。
- 物理：同向时按 moveAcceleration 逼近 ±moveSpeed。
- 物理：反向输入按 turnAcceleration，过 0 后换回 moveAcceleration。
- 物理：目标速度再乘姿态的移速乘数（下蹲时 0.5）。
- 退出：水平输入归零 → Idle；离地 → 按 vy 分 Jump / Fall。

## 五、Jump 地面跳上升期

- 进入：踩地，或离地仍在 coyoteTime 内且未消耗。
- 进入：跳键需在 inputBufferTime 内，冲刺中按跳无效。
- 进入：下蹲且 crouchAllowJump 关时不给跳，也不消费输入。
- 起跳帧：vy 直接写为 jumpSpeed，重力设为 riseGravity。
- 起跳帧：若已松键，立刻按 Jump Cut 截断一次。
- 上升期，松开跳跃键时，vy 乘 jumpCutMultiplier，重力改 jumpCutGravity。
- 上升期，按住跳且 0<vy<apexThreshold，重力改 apexGravity。
- 物理：水平按 Move 规则逼近，vy 只受重力与上限钳制。
- 退出：帧首 vy≤0 → Fall，并把重力设为 fallGravity。
- 补充：上升中被重新归入本态时不重复给速度。

## 六、AirJump 空中跳上升期

- 进入：离地，且土狼机会已用掉或已过期。
- 进入：剩余 maxAirJumps 次数 >0，跳键在缓冲窗口内。
- 进入：冲刺中或下蹲禁用跳跃时，同样不给。
- 起跳帧：vy 直接覆盖为 airJumpSpeed，重力设为 riseGravity。
- 物理：水平逼近、顶点悬停、松键截断都与 Jump 一致。
- 次数：每次成功起跳扣 1 次，落地那一帧回满。
- 退出：帧首 vy≤0 → Fall，并把重力设为 fallGravity。
- 现状：maxAirJumps 配 0，本态目前不可达。

## 七、Fall 下落期

- 进入：离地且帧首 vy≤0。
- 物理：有输入按 Move 规则逼近，无输入按 moveDeceleration 归零。
- 物理：重力恒为 fallGravity，vy 下限为 -maxFallSpeed。
- 退出：踩地后按有无水平输入切 Move 或 Idle。

## 八、Dash 冲刺

- 进入：冷却结束，冲键在 dashBufferTime 窗口内。
- 进入：踩地可直接冲，空中需 maxAirDashes 次数未用完。
- 进入：下蹲且 crouchAllowDash 关时不给冲，也不消费输入。
- 物理：进入时关闭重力，速度覆盖为 朝向×dashSpeed，vy 归零。
- 物理：持续期间不响应左右输入，也不能起跳。
- 退出：超过 dashDuration → 恢复重力，再按 vy 分 Jump / Fall。
- 次数：离地触发才扣空中冲刺次数，落地回满。

## 九、姿态机的切换

- 基础态是 Stand，IsDone 恒 false，只能被抢占切走。
- 踩地、按住 S、且不在"待松手"状态 → 进下蹲。
- crouchPrepareTime>0 进前摇，=0 直接进 Crouch。
- 前摇中不判起身，自己走完或被打断，抢占不插手。
- 被打断后要求先松开 S，否则按住会立刻被拖回前摇。

## 十、Stand 站立

- 进入：初始帧，或前摇结束/被打断后回到本态。
- 物理：身高与移速乘数都是 1，不限制跳跃与冲刺。
- 退出：无（IsDone 恒 false），只能由抢占切走。

## 十一、CrouchingTransition 下蹲前摇

- 进入：按住 S，且 crouchPrepareTime>0（空中也进，不判踩地）。
- 物理：身高倍率与移速乘数按同一条曲线推向蹲姿值。
- 物理：进度 = 已用时间 / crouchPrepareTime，封顶 1。
- 限制：进度未满仍可跳可冲，满的那一帧起开始限制。
- 打断：松开 S、或外部 InterruptToStand。
- 打断物理：身高与移速乘数瞬间回 1，不播回弹过渡。
- 退出：进度满 → Crouch；被打断 → Stand。

## 十二、Crouch 完全蹲下

- 进入：前摇走完，或前摇配 0 时直接进来（空中进蹲也走这条）。
- 物理：身高压到 crouchHeightRatio，碰撞体与墙探针同步。
- 物理：每帧重报移速乘数 crouchMoveSpeedScale，帧首会复位。
- 限制：crouchAllowJump / crouchAllowDash 关时禁跳禁冲。
- 限制：禁令不消费输入，起身后缓冲窗口内仍会生效。
- 退出：无（IsDone 恒 false），松开 S 且头顶有空间时由抢占切回 Stand。
- 起身探测：从蹲头顶向上扫到站头顶，触发器不算阻挡。

## 十三、姿态与移动的三条硬约束

- 姿态必须先于移动推进，否则按下蹲键那帧还能跳。
- 移速乘数是一次性的，姿态每帧都要重新提交。
- 身高只改碰撞体 size/offset，不压 transform.scale。

## 十四、重力与贴地

- 踩地且 vy≤0：钳为 0，不累积重力。
- 踩地时表现层先贴地并清零 vy，逻辑层只读结果。
- 其余情况：vy 每帧减去当前重力 × Δt。
- 速度钳制：上升上限 maxRiseSpeed，下落下限 maxFallSpeed。
- 重力来源：起跳写 riseGravity，顶点写 apexGravity。
- 重力来源：松键写 jumpCutGravity，跳跃结束写 fallGravity。
- moveAcceleration≤0 时，所有水平动作都当帧直达。

## 十五、外部速度修正

- 速度记两份：常规移动速度由 MoveGroup 各态提交，外部速度由 AddExternalVelocity 叠加。
- 移动状态只读写常规部分，覆盖不到外部部分；外部速度也不参与水平速度的逼近。
- 每帧帧首按 externalDeceleration × Δt 把外部速度朝 0 线性衰减，不会越过 0 反向。
- 帧首读刚体后先减去上帧写进去的外部速度，状态看到的始终只有常规速度。
- Commit 写回刚体的是「常规速度 + 外部速度」，所以移动状态改不到最终速度。
- 外部速度即使没有常规提交也要写回，否则衰减落不到刚体上，角色会一直被推着走。
- 撞墙、落地把速度清零时，外部冲量判定为已被物理消耗，不会剥成一份反向的常规速度。
- 瞬移（SpawnAt）会清空外部速度，旧冲量不会带到新位置。
- 后坐力：开火帧沿弹道反方向叠加一份外部速度，平射 / 斜上 / 斜下各读一份参数。

## 十六、攻击状态组（白）

- 与移动、姿态完全正交：不改移动状态，也不读姿态禁令。
- 基础态是 None，IsDone 恒 false，只能被抢占切走。
- 抢占条件：当前为 None、攻击键本帧按下沿、attackCooldown 已过。
- 冷却从触发攻击那一帧起算，不是从开火那一帧起算。
- attackPrepareTime>0 进前摇，=0 当帧直接进 WhiteAttack。
- 前摇只计时，不缓存攻击键；期间不响应新的攻击输入。
- WhiteAttack 是开火那一帧：Enter 里生成子弹并写后坐力，只停留一帧。
- 子弹起点取 WorldInfo.Pos（玩家中心），方向由 AttackAim 解析：水平分量取 WorldInfo.Face，竖直输入为正算斜上 45°、为负算斜下 45°，否则平射。
- 竖直输入取开火那一帧的 Move.y，阈值 0.5，避免摇杆漂移误触；朝向没定过时退回缩放方向，默认朝右。
- 后坐力沿弹道反方向叠加，平射读 recoilSpeedX、斜上读 recoilSpeedUp、斜下读 recoilSpeedDown，由外部速度自行衰减。
- attackRecoverTime>0 进后摇，=0 直接回 None；后摇期间同样不响应攻击输入。
- 后摇走完回 None，下一次攻击仍要过 attackCooldown。
- 攻击机排在移动机之后：开火方向要用本帧 MoveState 刚写入的朝向，后坐力则不再依赖帧序。

## 十七、状态流转图

```text
移动：Idle ⇄ Move
Idle/Move --离地--> Jump(vy>0) 或 Fall(vy≤0)
Jump/AirJump --vy≤0--> Fall
Fall --落地--> Idle 或 Move
任意状态 --冲刺键--> Dash --时长到--> 按 vy 回落

姿态：Stand --按住S--> 前摇(>0) 或 Crouch(=0)    （空中同样能进）
前摇 --进度满--> Crouch
前摇 --松键/外部打断--> Stand
Crouch --松键且头顶有空间--> Stand

攻击：None --攻击键且冷却过--> 前摇(>0) 或 WhiteAttack(=0)
前摇 --attackPrepareTime 到--> WhiteAttack --开火--> 后摇(>0) 或 None(=0)
后摇 --attackRecoverTime 到--> None
```

## 附注

- 掉出世界（y 低于 \_spawnY）时回到最近一次踩地的位置。
- 姿态的第一帧 Current 为 None，按站姿算，同帧即可进蹲。
- 姿态与踩地完全解耦：空中能蹲能起身，落地不会因为踩地判定掉帧被踢回站姿。
- 贴地吸附与探测参数在 MoveMotor，不在 PlayerConfig。
- 子弹预制体按需从 Resources/Prefabs/Bullet 懒加载，生成时补 Rigidbody2D 并写一次性速度。
- 子弹靠刚体速度飞行，不写 Update；离开 tag 为 Bound 的触发器时销毁自己。
- 场景尚未接入 Bound 触发器，子弹目前不会自动销毁。
- 下蹲时的独立弹道尚未实现，子弹仍从玩家中心（站立枢轴）射出。
