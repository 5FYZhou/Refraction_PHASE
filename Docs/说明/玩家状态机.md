# 玩家状态机

> 依据代码：MoveGroup（移动 6 态）、PostureGroup（姿态 3 态）、AttackGroup（攻击 7 态：白黑各 3 段 + None）、PlayerLogic 内置充能计时（3 阶段，不是状态组）。
> 速度逼近看 MoveLedger，探测/贴地/身高看 PlayerMotor，残影账本看 AfterimageLedger，生成与连线判定看 AfterimageLogic。
> 三套状态机正交：移动管速度与重力，姿态管身高、移速与动作禁令，攻击管开火、后坐力与黑白形态；充能计时与残影系统独立于三者。
> 每条按「时机 + 动作」写，一行一条。

## 一、每帧顺序

1. 采样世界：探地面、探墙，踩地时贴地吸附并清零 vy。
2. BeginStep：读真值并剥掉外部速度，清空增量，速度乘数复位，外部速度衰减一次。
3. 姿态机：定下本帧能否跳/冲、身高倍率与 View 目标值。
4. 移动机：先判抢占（冲刺优先于跳），再判状态是否结束。
5. 状态 Tick：提交本帧的水平逼近与重力设定。
6. 攻击机：排在移动机之后，开火那一帧生成子弹并叠加一份反向外部速度（后坐力）。
7. 充能计时：读本帧的冲刺起手，蓄满转待释放；冲刺起手时请求残影系统落影。
8. ApplyGravity：施加当前重力，钳制上升与下落速度。
9. Commit：有提交或外部速度在变才写回，写的是「常规速度 + 外部速度」。
10. 渲染帧：把姿态给的缩放落到 View，以脚底为锚点。

- 过门请求插在 BeginStep 之后：TransitMotor 先换输入，再进姿态与移动。
- 姿态看到的是替换后的输入：下蹲键为假，蹲姿会按起身判定切回。
- 残影系统排在玩家之后：CombatRoot 在同一物理帧里推进 AfterimageLogic（清过期）并刷新 AfterimageField。

## 二、移动机的抢占与回落

- 抢占顺序固定：先判冲刺，再判跳跃（地面跳 / 空中跳）。
- 抢占必须成功消费对应输入，否则本次抢占作废。
- 目标与当前状态相同则不切换，直接继续 Tick。
- 当前状态 IsDone 后，按基础态规则回落。
- 基础态：离地且帧首 vy>0 → Jump，否则 → Fall。
- 基础态：踩地且有水平输入 → Move，否则 → Idle。
- 落地那一帧：清土狼消耗、空中跳次数、空中冲刺次数。

## 三、Idle 地面待机

- 进入：踩地且无水平输入（落地后或松键后）。
- 物理：每帧按 moveDeceleration 把 vx 收敛到 0。
- 物理：踩地且 vy≤0 时 vy 钳为 0，贴地不下沉。
- 退出：有水平输入 → Move；离地 → 按 vy 分 Jump / Fall。

## 四、Move 地面行走

- 进入：踩地且有水平输入。
- 物理：同向时按 moveAcceleration 逼近 ±moveSpeed。
- 物理：反向输入按 turnAcceleration，过 0 后换回 moveAcceleration。
- 物理：目标速度再乘姿态的移速乘数（下蹲时 0.5）。
- 退出：水平输入归零 → Idle；离地 → 按 vy 分 Jump / Fall。

## 五、Jump 地面跳上升期

- 进入：踩地，或离地仍在 coyoteTime 内且未消耗。
- 进入：跳键需在 inputBufferTime 内，冲刺中按跳无效。
- 进入：下蹲且 crouchAllowJump 关时不给跳，也不消费输入。
- 起跳帧：vy 直接写为 jumpSpeed，重力设为 riseGravity。
- 起跳帧：若已松键，立刻按 Jump Cut 截断一次。
- 上升期，松开跳跃键时，vy 乘 jumpCutMultiplier，重力改 jumpCutGravity。
- 上升期，按住跳且 0<vy<apexThreshold，重力改 apexGravity。
- 物理：水平按 Move 规则逼近，vy 只受重力与上限钳制。
- 退出：帧首 vy≤0 → Fall，并把重力设为 fallGravity。
- 补充：上升中被重新归入本态时不重复给速度。

## 六、AirJump 空中跳上升期

- 进入：离地，且土狼机会已用掉或已过期。
- 进入：剩余 maxAirJumps 次数 >0，跳键在缓冲窗口内。
- 进入：冲刺中或下蹲禁用跳跃时，同样不给。
- 起跳帧：vy 直接覆盖为 airJumpSpeed，重力设为 riseGravity。
- 物理：水平逼近、顶点悬停、松键截断都与 Jump 一致。
- 次数：每次成功起跳扣 1 次，落地那一帧回满。
- 退出：帧首 vy≤0 → Fall，并把重力设为 fallGravity。
- 现状：maxAirJumps 配 0，本态目前不可达。

## 七、Fall 下落期

- 进入：离地且帧首 vy≤0。
- 物理：有输入按 Move 规则逼近，无输入按 moveDeceleration 归零。
- 物理：重力恒为 fallGravity，vy 下限为 -maxFallSpeed。
- 退出：踩地后按有无水平输入切 Move 或 Idle。

## 八、Dash 冲刺

- 进入：冷却结束，冲键在 dashBufferTime 窗口内。
- 进入：踩地可直接冲，空中需 maxAirDashes 次数未用完。
- 进入：下蹲且 crouchAllowDash 关时不给冲，也不消费输入。
- 物理：进入时关闭重力，速度覆盖为 朝向×dashSpeed，vy 归零。
- 物理：持续期间不响应左右输入，也不能起跳。
- 退出：超过 dashDuration → 恢复重力，再按 vy 分 Jump / Fall。
- 次数：离地触发才扣空中冲刺次数，落地回满。

## 九、姿态机的切换

- 基础态是 Stand，IsDone 恒 false，只能被抢占切走。
- 踩地、按住 S、且不在"待松手"状态 → 进下蹲，空中不给蹲。
- crouchPrepareTime>0 进前摇，=0 直接进 Crouch。
- 蹲姿起身要两个条件：松开 S，且头顶有站直空间。
- 前摇中不判起身，自己走完或被打断，抢占不插手。
- 被打断后要求先松开 S，否则按住会立刻被拖回前摇。
- 蹲姿与前摇的离地判定走 crouchGroundGrace 宽限，不读原始踩地。

## 十、Stand 站立

- 进入：初始帧，或前摇结束/被打断后回到本态。
- 物理：身高与移速乘数都是 1，不限制跳跃与冲刺。
- 退出：无（IsDone 恒 false），只能由抢占切走。

## 十一、CrouchingTransition 下蹲前摇

- 进入：踩地且按住 S，crouchPrepareTime>0；空中进不来。
- 物理：身高倍率与移速乘数按同一条曲线推向蹲姿值。
- 物理：进度 = 已用时间 / crouchPrepareTime，封顶 1。
- 限制：进度未满仍可跳可冲，满的那一帧起开始限制。
- 打断：松开 S、离地超 crouchGroundGrace、外部 InterruptToStand。
- 打断物理：Exit 只回身高，移速乘数下一帧帧首才复位。
- 退出：进度满 → Crouch。
- 退出：被打断 → 头顶能站直回 Stand，站不直就地进 Crouch（硬回站高会顶进天花板）。
- 外部打断：InterruptToStand 在头顶不足时直接返回 false，不切状态。

## 十二、Crouch 完全蹲下

- 进入：踩地，前摇走完；或前摇配 0 时按住 S 直接进来。
- 物理：身高压到 crouchHeightRatio，碰撞体与墙探针同步。
- 物理：每帧重报移速乘数 crouchMoveSpeedScale，帧首会复位。
- 限制：crouchAllowJump / crouchAllowDash 关时禁跳禁冲。
- 限制：禁令不消费输入，起身后缓冲窗口内仍会生效。
- 退出：离地超 crouchGroundGrace → 头顶能站直回 Stand，站不直留在蹲姿（本态唯一的自结束）。
- 退出：松开 S 且头顶有空间时，由抢占切回 Stand。
- 起身探测：从蹲头顶向上扫到站头顶，触发器不算阻挡。

## 十三、姿态与移动的三条硬约束

- 姿态必须先于移动推进，否则按下蹲键那帧还能跳。
- 移速乘数是一次性的，姿态每帧都要重新提交。
- 身高只改碰撞体 size/offset，不压 transform.scale。

## 十四、重力与贴地

- 踩地且 vy≤0：钳为 0，不累积重力。
- 踩地时表现层先贴地并清零 vy，逻辑层只读结果。
- 其余情况：vy 每帧减去当前重力 × Δt。
- 速度钳制：上升上限 maxRiseSpeed，下落下限 maxFallSpeed。
- 重力来源：起跳写 riseGravity，顶点写 apexGravity。
- 重力来源：松键写 jumpCutGravity，跳跃结束写 fallGravity。
- moveAcceleration≤0 时，所有水平动作都当帧直达。

## 十五、外部速度修正

- 速度记两份：常规移动速度由 MoveGroup 各态提交，外部速度由 AddExternalVelocity 叠加。
- 移动状态只读写常规部分，覆盖不到外部部分；外部速度也不参与水平速度的逼近。
- 每帧帧首按 externalDeceleration × Δt 把外部速度朝 0 线性衰减，不会越过 0 反向。
- 帧首读刚体后先减去上帧写进去的外部速度，状态看到的始终只有常规速度。
- Commit 写回刚体的是「常规速度 + 外部速度」，所以移动状态改不到最终速度。
- 外部速度即使没有常规提交也要写回，否则衰减落不到刚体上，角色会一直被推着走。
- 撞墙、落地把速度清零时，外部冲量判定为已被物理消耗，不会剥成一份反向的常规速度。
- 瞬移（SpawnAt）会清空外部速度，旧冲量不会带到新位置。
- 后坐力：开火帧沿弹道反方向叠加一份外部速度，平射 / 斜上 / 斜下各读一份参数。

## 十六、攻击状态组（白 / 黑）

- 与移动、姿态完全正交：不改移动状态，也不读姿态禁令。
- 基础态是 None，IsDone 恒 false，只能被抢占切走。
- 抢占条件：当前为 None、攻击键本帧按下沿、attackCooldown 已过。
- 冷却从触发攻击那一帧起算，不是从开火那一帧起算。
- attackPrepareTime>0 进前摇，=0 当帧直接进 WhiteAttack。
- 前摇只计时，不缓存攻击键；期间不响应新的攻击输入。
- WhiteAttack 是开火那一帧：Enter 里生成子弹并写后坐力，只停留一帧。
- 弹道：起点取 WorldInfo.Pos，水平分量取 WorldInfo.Face。
- 弹道：Move.y>0.5 算斜上 45°，<-0.5 算斜下 45°，否则平射。
- 阈值 0.5 吸收摇杆漂移，取的是开火那一帧的 Move.y。
- 朝向没定过时退回缩放方向，默认朝右。
- 后坐力沿弹道反向叠加，走外部速度并自行衰减。
- 平射读 recoilSpeedX，斜上读 recoilSpeedUp，斜下读 recoilSpeedDown。
- 蹲姿倍率 crouchRecoilScale 乘在上述三项之后，按 PostureGroup.CrouchProgress 从 1 线性插值：
  半蹲取中间值，蹲满才是设定倍率；空中不给蹲，所以空中开火恒为站立倍率。
- attackRecoverTime>0 进后摇，=0 直接回 None；后摇期间同样不响应攻击输入。
- 后摇走完回 None，下一次攻击仍要过 attackCooldown。
- 子弹命中不顿帧：子弹的 `IHitLanded` 只接到 `PlayerLogic.OnHitLanded`（涨极性），
  顿帧挂在近战那条 `OnMeleeHitLanded` 上；敌人子弹打到玩家顿的是 `contactHitStopTime`。
- 攻击机排在移动机之后：开火方向要用本帧 MoveState 刚写入的朝向，后坐力则不再依赖帧序。

### 黑形态

- 形态跟着世界极性走：订阅 `WorldPolarityChanged`，`IsBlack = (World == Black)`，不是自己数翻转次数。
  进关时 `LevelManager.Init` 会补发一次当前极性，所以上一关留下的黑世界，这一关开局就是黑形态。
- 反转只翻标记：正在走的那一套不打断，前摇中途反转仍打完本套，下一次攻击才用新形态。
- 黑形态只有三只近战状态，按攻击键那一帧由竖直输入决定进哪一只（`AttackAim.Kind`）：
  **平劈** `FlatAttack`、**斜上突进** `BlackDashUp`、**斜下突进** `BlackDashDown`。
  三只共用 `AttackPhaseState` 骨架，**前摇 / 本体 / 后摇三段收在自己身上**（`Prepare → Active → Recover → Done`），
  不再拆成六段互相接力；段长为 0 就当场跳过下一段。
  三只占同一个攻击位置（`AttackGroup` 的抢占），天然不能同时存在；**只和攻击互斥**，弹反不受影响。
- 段推进由 `AttackGroup` 每帧在状态切换判定之前调一次 `Advance`：走满一段就 +1，
  所以"前摇走满进本体"与原来多状态接力落在同一帧；`Done` 之后 `Fallback` 回 `None`。
- 抢占规则：**只有空闲与后摇能被别的攻击顶掉**（`Cancelable` 只在 `Recover` 为真）；
  前摇与本体一律不许（包括同方向再按、换方向按），也**不会重启**——目标标签与当前相同就直接放弃抢占。
- 普攻本体是**持续状态**（`flatAttackTime`），不是一帧；判定固定 `Player/BlackDash/AheadCollider`，
  进本体那一帧由 `BlackAttackView.BeginFlat` 点亮，`Exit` 时 `End` 关掉。
- 三只盒（`Player/BlackDash/{Ahead,Up,Down}Collider`）共用同一份 `IAttacker`：
  普攻读 `flatAttackDamage` / `flatAttackKnockback`，突进读 `blackDashDamage` / `blackDashKnockback`，方向随判定与朝向。
- 盒被点亮时会把它的真实碰撞形状画成半透明网格（`Collider2D.CreateMesh` + `MeshRenderer`，`BlackAttackView.Paint`）：
  网格顶点就在盒的局部空间，子物体随盒一起显隐，形状与判定完全一致，不用再靠包围盒估。
  `CreateMesh` 拿不到网格时按 collider 自己的路径点 / 尺寸拼三角面兜底（`BlackAttackView.ShapeMesh`）。
- 普攻的后坐力分两份：空挥 `flatAttackMissRecoil`、命中 `flatAttackHitRecoil`，都沿朝向反向推（只有横向）。
  `Enter` 当场写上空挥那份，所以砍空气也有后坐；判定盒真碰到受击盒（`AttackBox` 每接触一次都会先取伤害 →
  `BlackAttackView.ProduceDamage` → `FlatAttackState.NotifyHit`）时**把空挥那份换成命中那份**。
  只要砍在实体上就算命中，扣没扣到血（无敌窗、关掉 AI 的站桩靶子）不影响反冲；涨极性值才只认真扣血。
- 换的是"再写一次"，不是相加，一次挥击只换一次（同帧砍到多个目标也只换一次），`Exit` 后迟到的命中不再换。
- **命中那份不能当场写**：`AttackBox` 的接触回调发生在物理步里，也就是本帧 `Commit` 之后，
  那一刻改的速度会在下个 `BeginStep` 被 `_delta` 复位吃掉。所以 `NotifyHit` 只置 `_hitQueued`，
  真正的 `Apply` 放到下一帧的 `Tick`（`Exit` 也补一次），赶在 `ApplyGravity`/`Commit` 之前落地。
- 两份都乘 `crouchRecoilScale`，**直接写速度**（`SetVelocityX`），不走外部速度：
  反冲是瞬时的，进状态当帧盖掉横向速度，之后回归移动组的加减速与重力。
- 不挂 `IIntervalAttacker`：判定盒只在挥击期间存在，`OnTriggerEnter` 天然一次挥击一次命中，同帧多个目标都能吃到。
- 三段各自读自己的字段：平劈 `flatAttack*`、斜上 / 斜下 `blackDash*`（时长、速度、伤害、击退各一套）。
- **冷却也是三份**，各计各的、互不占位：平劈 `flatAttackCooldown`、斜上 `blackDashUpCooldown`、
  斜下 `blackDashDownCooldown`，都从按下攻击键那一刻起算。白形态仍用 `attackCooldown`；切换形态不清冷却。
- **受击（`ConditionGroup.IsHurt`）期间攻击键不生效**，不起新的一套；已经起手的那套不打断，照常打完。
  门禁在 `AttackGroup.TryDecidePreempt`，受击态由条件组在攻击组之前推进，所以挨打当帧就拦得住。
- **判定盒点亮后脱开玩家、冻在世界里**（普攻）：`BlackAttackView.BeginFlat` 把 Ahead 那只盒 `SetParent(null, true)`，
  之后玩家跑开判定也不跟着走；`End` 关掉并按 `Anchor` 记下的原父级与局部 TRS 装回 `BlackDash` 下，
  下一次攻击再按当时的站位重新摘一次。冻住期间按开打那一帧的朝向（`_swingFace`）结算方向，中途转身不镜像。
  突进盒（Up / Down）相反，不摘父级，整段跟着玩家跑。
- 盒被摘走后 `transform.root` 只剩自己，`AttackBox` 靠 `Awake` 缓存的 `_selfRoot` 才认得出本体，否则会打到玩家自己。
- **弹反范围**在 `Player/BlackRebound/{Ahead,Up,Down}Collider`，开关归逻辑层（`ReboundGroup` → `IReboundView`，
  表现端 `BlackAttackView.ShowRebound` / `HideRebound`），与近战状态互不相干：近战 `End` 不会顺手关掉它。
- **只有黑形态才有弹反**；它的时长跟按键绑定（和跳跃一样）：按下攻击键就开，松键当帧即关。
  按住期间最多开 `reboundMaxTime` 秒，到点即使还按着也自动关。
- 方向键只决定**朝哪开**，不再是开启条件：W → 斜上、S → 斜下、A / D → 正前偏左 / 偏右，
  **没按方向就按当前朝向开正前**；斜向的左右取**当前速度方向**（速度近 0 时回落到朝向）。
- **冷却从关掉那一刻起算**（不是从按下起算），走完 `reboundCooldown` 才能再开。
  本轮按住只要开过一次就不再自动重开——到点关掉后手不松跨过冷却也不会自己亮，必须松开再按。
- 世界转回白时已开着的弹反当帧收掉（白形态按住攻击键不开弹反）。
- 它**不脱开玩家**：留在玩家层级里，靠 `BlackRebound` 的 `localScale.x` 翻到指令那一侧（与根节点朝向相反时再翻一次），
  局部 TRS 一律不动。这与攻击盒"摘下来冻住"是两条相反的处理，别把弹反盒也挂进 `Anchor` 那套。
- 弹反范围同样在运行时画出真实形状：复用 `BlackAttackView.Paint`，只是换一份**明黄**的半透明材质
  （攻击盒是紫色）。网格是盒的子物体，盒不点亮时跟着隐藏，看到什么形状就是弹反什么形状。
- 子弹的碰撞面在 `Bind` 时按伤害源改写（`Bullet.ApplyHitMask`），两侧都排掉 Default 层，弹反盒收不到 `OnTriggerEnter2D`；
  判定因此不走物理回调，改成**每物理帧扫一遍活子弹**（`Bullet.LiveCount` / `LiveAt` + `Collider2D.OverlapPoint`），
  "刚飞进来"和"开打时已经在里面"是同一套判定，不需要 `OnTriggerStay2D`。
- 只有敌弹会被弹：`Bullet.PlayerOwned == false`。命中后 `Bullet.TryReflect` 把**玩家自己的** `IBulletLauncher`
  叫到原位置反向重发一发（速度沿用打进弹反区的那一发，伤害 / 击退 / 传输速度取 `bulletDamage` /
  `bulletKnockback` / `bulletTransferSpeed`），原弹当帧从敌方系统收走。新弹属于玩家侧，能打敌人，也能进残影。
- 优先级：子弹中心落在身体受击盒的包围盒里时不弹反（`BlackAttackView.InHurtRange`），让受击判定先走。
  按设计身体受击范围与弹反范围不重叠，这条只在两者真的压在同一颗子弹上时生效。
- 玩家销毁时 `PlayerController.OnDestroy` 调 `PlayerLogic.Dispose` 退订 `WorldPolarityChanged`：静态事件总线不会自己忘掉旧实例。

### 黑形态的普攻与突进

- 普攻本体不压移动组，前摇 / 后摇只是计时；判定盒在开打那一帧摘下来冻住（与 `Anchor` 那套同源）。
  普攻的数值全在 `flatAttack*`（三段时长 / 伤害 / 击退 / 两份反冲 / 冷却），与突进各成一套。
- 命中经 `AttackGroup.OnBlackHit` 转到 `FlatAttackState.NotifyHit`，反冲仍写在下一帧。
- 前摇（突进）：**起手那一帧就把移动组压成 `Fall`**（`PlayerLogic` 读 `AttackGroup.HoldsMoveFall` 直接 `ChangeState`，
  所以哪怕站在地上起手，状态也不是 Idle / Move）；移动组整段被压住（`MoveGroup.Blocked`）；**速度每帧锁成 0、重力也关掉**，
  所以这一段时间既不能走、也不能冲、更不会被重力拽下来，但照常能被打中、正常掉血。
  **方向在按下那一刻就定了**（斜上 / 斜下本来就是两只状态），前摇里改输入不换方向。
  挨打（`ConditionGroup.IsHurt`）整段作废回 None，`Exit` 负责把重力还回来。
- 本体：`SetGravityEnable(false)`，进入那一帧写死速度 `方向 × blackDashSpeed{Up / Down}`，之后不再写；
  移动组仍被压住，所以没有谁去改它。**整段无敌**（`BeginDashInvulnerable(blackDashTime{方向})`），
  时长读 `blackDashTime{Up / Down}`，斜上 / 斜下各一套速度与时长。
  本体**不虚化**：虚化是 ConditionGroup 里另一个计时器（`BeginPhase`），只有充能落影会开它。
- 起手限制：**站在地面不能下突进**。分流时 `BlackTarget` 读 `WorldInfo.Grounded`，斜下 + 踩地直接返回
  `None`、连抢占都不做（不消耗冷却）；斜上不受限制，空中三个方向都能起手。
- 本体会提前结束，两种都是「在 `Advance` 里记到就当场 `SkipToRecover`」：
  - **打到第一个目标**：`ProduceDamage` 走 `SetHitHandler` 那条钩子 → `AttackGroup.OnBlackHit` →
    `BlackDashState.NotifyHit`。进后摇那一帧把竖直速度直接换成 `blackDashBounceSpeed`（向上弹起），
    横向保留冲出去的那一份，靠刚恢复的重力自然落回来。
  - **撞到墙**（`WorldInfo.TouchingWall`，探针走的就是朝向那一侧）：进后摇时把速度整体清成 0 再恢复重力，
    停在墙前。
  两种情况都提前进后摇，突进盒在 `End` 里关掉。
- 伤害：本体 `Enter` 调 `BlackAttackView.BeginDash`，点亮 `BlackDash` 下对应的突进盒（斜上 / 斜下）。
  突进盒不摘父级、整段跟着玩家跑，撞到受击盒按 `blackDashDamage` 扣血、沿突进方向按 `blackDashKnockback` 击退。
  三只盒共用一份 `HitLedger`（`BeginDash` 清空）：**一次突进对同一个受击盒只结算一次**，不同目标各自吃一次。
  `Exit` 时 `End` 一并关掉。
- 突进命中不套普攻的反冲（`BeginDash` 那条路不写反冲），但命中仍走 `IHitLanded`：
  经 `PlayerLogic.OnMeleeHitLanded` 涨极性，并发 `RequestHitStop(meleeHitStopTime)` 顿帧。
  这条**只在真扣到血时才走**（`AttackBox` 拿到 `TakeDamage` 返回 true 才回调），无敌窗挡住的那次既不涨极性也不顿。
  普攻同理：`SetHitHandler` 那条 `OnBlackHit` 在扣血之前就回调，只负责换后坐力 / 提前结束，顿帧看的是另一条路。
- 展示：突进盒的真实碰撞形状画成**紫色**（`Range` 网格，挂在盒下随盒移动 = 实时位置）；
  起手那一帧再按「起手形状 ∪ 终点形状」的凸包画一片**绿色**（`DashSweep`，顶点是世界坐标、不挂父级），
  也就是这一段突进扫过的范围，`End` 时销毁。绿色 `sortingOrder` 比紫色小，压在下面不挡实时范围。
- 后摇：进后摇那一帧重力就还回来；移动组不再压住（`BlocksMovement` 只覆盖前摇与本体），
  **可以照常移动**，冲出去的速度按移动减速自然衰减。还留在 `Fall` 里，踩地那一帧才 `Fallback` 回 Idle / Move。
  但跳跃 / 冲刺不接受：`AttackGroup.BlocksActions` 经 `MoveGroup.ActionsBlocked` 只拦抢占，移动状态照常推进。
- 后摇能被**别的方向**的攻击直接顶掉（`TryDecidePreempt` 放行 `Cancelable`）；
  **同方向再按不会重开**——`StateGroup.CheckChange` 发现目标标签与当前相同就放弃抢占，仍停在后摇里。

## 十七、充能与残影（PlayerLogic + AfterimageLogic）

- 充能**不是状态组**：没有基础态、没有抢占，只有 PlayerLogic 里的一个计时器。
- 计时器插在攻击组之后；排在此处是因为它要读本帧的冲刺起手。
- 三阶段：None（空闲）、Charging（前摇）、Charged（蓄满待释放）。
- 起蓄条件：当前为 None、充能键**按下沿**、chargeCooldown 已过。
- 黑形态（世界极性为 Black）不能充能：计时器开头先看极性，黑时直接把阶段复位到 None 并返回，
  按键完全不响应，也不会起冷却。
- 翻黑那一刻就复位充能阶段，并把场上残影一并清掉（IAfterimageSpawner.Clear）：
  黑世界里不留下白色的连线伤害与子弹传输，充能、残影、连线三样都只在白形态发生。
- 极性由 PlayerLogic 自己订阅 WorldPolarityChanged 得知，不向攻击组借 IsBlack；订阅在构造函数，
  退订在 Dispose（静态事件总线，漏退订会攒住旧实例）。
- 充能键是「按一下」触发，不需要按住；松手不会取消。
- chargePrepareTime>0 进 Charging 计时，=0 按下当帧直接 Charged。
- 前摇走满转 Charged 并调 IAfterimageSpawner.Arm()，不会自己回落，一直保持到冲刺释放。
- 冲刺起手那一帧 PlayerLogic 调 IAfterimageSpawner.TrySpawn(位置, 时间)，生不生成由残影系统判断。
- TrySpawn 只在已 Arm 且名额可用时返回 true；返回 true 才起 chargeCooldown 并回 None。
- 冲刺起手判定：移动机推进前后的标签由非 Dash 变 Dash 的那一帧。
- 前摇没走完就冲刺：这次冲刺不落影，充能继续进行，不算浪费。
- 冷却从落影那一刻起算，不是从按键起算；冷却中按键完全无效。
- 落影当帧给 dashInvulnerableTime（秒）的无敌：窗口内任何伤害都不结算，也不进受伤态、不吃击退。
- 这段无敌就是**虚化**：`PlayerController.ApplyPhase` 在物理帧把 HurtCollider 的 ExcludeLayers 临时并上 `Bullet(11)`，
  子弹连接触都不产生，直接穿过玩家——不是「打中了不扣血」，所以子弹也不会消失。
  近战与接触伤害仍会碰到受击盒，靠无敌窗挡伤害。
- 虚化在 ConditionGroup 里是**独立计时器**（`BeginPhase` / `IsPhasing`）：和冲刺无敌同一帧、同一个
  dashInvulnerableTime 开，但各自记时——黑突进只开无敌、不开虚化，别把它俩并成一个判断。
- 冲刺无敌独立于受击无敌窗（ConditionGroup 里三个计时器：受击无敌 / 冲刺无敌 / 虚化）：表现层给冲刺无敌设固定透明度，受击无敌窗才是闪烁。
- 充能计时的代码在 `Logic/Actor/Player/PlayerLogic.cs`，ChargePhase 是同目录的独立枚举。
- AfterimageLogic 持有并驱动账本：落影、上限顶替、过期清理、连线判定都在它这里。
- AfterimageLedger 退化为纯数据：只按生成顺序存 Afterimage，暴露 Count 与索引器。
- 残影只记位置、落地时刻与生成序号，由 AfterimageLedger 统一记账。
- 残影到 afterimageDuration 自动过期，按生成顺序从最早一枚开始清。
- 场上满 maxAfterimages 时顶掉最早的一枚，不拒绝放置。
- 连线取生成顺序相邻的两枚，末枚接回首枚；两枚时只有一条。
- 相邻两枚间距超 afterimageLinkSenseRadius 时不连线，避免跨图拉超长线。
- 连线判定是一根绕中点旋转的方块：长取间距，宽取 afterimageLinkThickness。
- 连线平时只是画出来的线，**不结算持续伤害**；只有子弹正沿着某条连线传输时才结算。
- 每次结算沿线扫一遍，每个真吃到伤害的目标发一次 AfterimageLinkHit（带命中点与伤害值）；
  PlayerLogic 订阅它并按 afterimageLinkPolarity 加极性值，与子弹命中的 polarityPerHit 分开配。
- 重生（死亡回档、跨场景回档）走 SpawnTo：先调 IAfterimageSpawner.Clear() 清账本与待释放状态，再挪人，
  出生点不会带着上一段路留下的残影与连线。
- 掉虚空不算重生：回落脚点走 FallBackTo，它和 SpawnTo 共用私有的 Place，**不清残影**，
  场上残影与连线原样保留，靠 afterimageDuration 自然过期。
- 两个入口一一对应：RespawnToLastGrounded 给死亡兜底（清），FallBackToLastGrounded 给掉虚空（不清），别用错。
- 表现层 AfterimageField 由 CombatRoot 创建成自己的子物体，不挂在玩家身上：玩家重生或销毁都不影响场上残影，也不写进 Player.prefab。
- 表现层残影是冲刺那一刻 View 的定妆克隆：行为与碰撞体一律关掉，落影帧拍一次姿态后就固定。
- 槽位按残影序号绑定，不按队列位置：最老一枚过期时不会把还活着的残影重拍成现在的样子。
- 残影体走 Foundation 的 Pool<Slot>：容量取 maxAfterimages 并预先造好，过期回收进池复用。
- 残影随时间从 afterimageAlpha 线性淡到写死的终止透明度（0.12），最后一秒按 6Hz 闪烁。
- 淡出与闪烁的三个常量写在 AfterimageField 里，先不开放成配置。

## 十八、子弹在残影间传输

- 残影外壳是 Resources/Prefabs/AfterImage：Collider 子物体就是吸引子弹的判定范围，View 子物体是玩家 View 的运行时副本。
- 子弹只有两个状态：Flying（靠刚体速度直线飞）与 Transporting（关掉碰撞、按路径逐段位移）。
- 进入第一枚残影时当场算完 TransferPlan 并锁定：从入口按生成顺序往后走，绕到入口那一格为止。
- 相邻两枚的间距超过 afterimageLinkSenseRadius 就不再往下走，路径停在当前这一枚。
- 每一段出发前都回残影系统验活：目标被顶掉或过期就立刻终止传输，在当前有效位置恢复飞行。
- 传输速度取 bulletTransferSpeed，0 表示瞬移到下一枚。
- 传输途中不结算伤害也不吃碰撞；出射时碰撞体刚恢复会重复触发一次进入，靠子弹自己的「已传输」标记挡掉。
- 一颗子弹只被接管一次：出射后标记作废，之后飞回任何残影都不再进入传输，避免在两枚残影之间来回弹成死循环。
- 出射方向：水平分量取残影朝向，垂直分量沿用进入时的飞行方向。
- 例外：子弹若**顶着**入口那枚残影的朝向飞进来（进入方向与残影朝向水平相反），水平分量反号；
  否则它一进链就被原路弹回。顺着残影飞进来的照旧沿残影朝向出射。
- 出射后恢复 Dynamic 与 bulletSpeed，和普通子弹一样结算伤害。
- 只传输玩家自己发出的子弹：按开火者与残影的 playerRoot 比对。
- 路径至少得有一跳（入口加下一枚）：场上只有一枚残影时不接管子弹，子弹按原轨迹直接飞过去。
- 子弹每走一段，都通过残影身上的 AfterimageAnchor 拿到 AfterimageField，报告 BeginTraverse(起点序号, 终点序号)。
- 被穿的那条连线在传输期间变成不透明（alpha 取 1），走完这一段或被中断就恢复 afterimageLinkColor 的透明度。
- 同一条连线可能同时有几颗子弹在走，热度按次数叠加，走完一颗只减一次，全走完才恢复。
- 沿线伤害在这个 BeginTraverse 时刻结算**一次**：判定方块与画出来的线完全重合，同一次结算里同一个受击盒只吃一刀。
- 结算不受传输速度影响，也和子弹是否真的走到终点无关：一进这段线就结算。
- 子弹的逻辑在 `Logic/Combat/Bullet/BulletLogic`（实现 IBulletLauncher），表现外壳是 `Presentation/Combat/Bullet/Bullet`，由 `BulletField` 造。
- 子弹外壳走 Foundation 的 Pool<Bullet>：上限 32、预热 8，CreateOrDrop 策略；取用时 SetActive(true)，回收时 Reset + SetActive(false)，不 Destroy。
- 伤害由子弹自己身上的 AttackBox 结算：Bind 里 SetAttack(this)，结算成功（血量真的掉了）回调 OnHitLanded，立刻把这一发还池。
- 敌弹例外：撞到受击盒就自己结算并收弹，不看 TakeDamage 的返回值——受击无敌窗里也照样消失，不会贴着人等到窗口结束再扣一次。
  冲刺虚化期又是另一种：受击盒排掉了 Bullet 层，连 `OnTriggerEnter2D` 都不会来，子弹原样飞走。
- 一发子弹只对一个敌人结算一次：OnHitLanded 先判「已结算」标记，回收时再摘掉 AttackBox 的攻击者，同帧剩下的受击盒回调全部空转。
- 撞到敌人层时 Bullet 不自己收池，交给 AttackBox 结算：池化后 SetActive(false) 会当场掐断碰撞，先收就把这一枪吞了。
- 命中站桩靶子（EnemyController 关掉 OpenAI）也回池：EnemyLogic.TakeDamage 把伤害值抹成 0 后仍返回 true，AttackBox 照常回调 OnHitLanded。
- 残影逻辑在 `Logic/Combat/Afterimage`，残影与连线的表现是 `Presentation/Combat/Afterimage`。
- `CombatRoot` 在物理帧统一 Tick 子弹逻辑，`Bullet` 自己不注册场景根、不写 Update：它只把姿势落到刚体与碰撞体上，并把触发器回调转给逻辑层。

任意状态 --冲刺键--> Dash --时长到--> 按 vy 回落

## 附注

- 掉出世界（y 低于 \_spawnY）时回到最近一次踩地的位置。
- 姿态的第一帧 Current 为 None，按站姿算，同帧即可进蹲。
- 姿态与踩地是耦合的：进蹲要真踩地，蹲住后靠 crouchGroundGrace 容忍掉帧。
- 进蹲看原始踩地，蹲姿/前摇看宽限：两者不同源，别把 CanCrouch 也换成宽限。
- 离开蹲姿的每条路都要过 CanStandUp：松键起身走抢占，离地超宽限与前摇被打断走 Fallback，站不直就留在蹲姿。
- InterruptCrouch 已暴露到 PlayerLogic，但目前没有任何调用方。
- 离开蹲姿那一帧仍沿用上一帧的移速乘数，下一帧帧首才复位。
- 贴地吸附与探测参数在 PlayerMotor，不在 PlayerConfig（MoveMotor 只管刚体与速度账本）。
- 参数资产只挂在 PlayerController 上，装配时 `moveMotor.BindConfig(config)` 注入给 PlayerMotor；马达自己不再序列化 config。
- 子弹预制体由 CombatRoot 指定，留空则懒加载 Resources/Prefabs/Bullet；Bullet 在 Bind 时补 Rigidbody2D（只补一次，之后池里复用）并记住自己的伤害。
- 子弹靠刚体速度飞行；传输段由 BulletLogic 逐段摆位，两者都在 CombatRoot 的物理帧里推，Bullet 不写 Update。
- Bound 只在 Level_1 接进 Bound 层，其余关卡还在 Default：那几关的子弹飞出地图不会回池，只能靠撞 Ground 或命中敌人收掉。
- 下蹲时的独立弹道尚未实现，子弹仍从玩家中心（站立枢轴）射出。
- 充能键绑在 O（InputSys.inputactions 新增的 Charge 动作，手柄西键）；生成物要等编辑器重导入后才带该属性，
  所以 InputProvider 按名字 FindAction("Charge")，找不到只报一次警告，不影响编译。
- 残影落点是世界坐标：账本里的 Pos 加「落影帧 View 相对玩家枢轴的偏移」，参照系是玩家枢轴，不是 AfterimageField 自己的 Transform。
- 残影槽位挂在 CombatRoot 的容器下，缩放要除掉容器继承来的那一层，否则会被放大两次。
- 残影与连线的表现挂在 AfterimageField：由 CombatRoot 在 Attach 时创建为自身子物体并每物理帧驱动。
- 连线用运行时生成的 1×1 白图按 1 像素 = 1 米拉伸，不依赖美术给方形图。
- 蓄满贴图不用限时：Charged 是个持续状态，冲刺释放前一直挂着那张图。
- 充能配色写死在 PlayerController（黄 → 橙），配置里只留两张贴图，避免美术换色还要改资产。
- 残影快照里的颜色与贴图取的是落影那一帧 View 的样子，之后本体换装不影响已落下的残影。
