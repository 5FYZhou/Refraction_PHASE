# 玩家状态机

> 依据代码：MoveGroup（移动 6 态）、PostureGroup（姿态 3 态）、AttackGroup（攻击 4 态）、PlayerLogic 内置充能计时（3 阶段，不是状态组）。  
> 速度逼近看 MoveLedger，探测/贴地/身高看 PlayerMotor，残影账本看 AfterimageLedger，生成与连线判定看 AfterimageLogic。  
> 三套状态机正交：移动管速度与重力，姿态管身高、移速与动作禁令，攻击管开火与后坐力；充能计时与残影系统独立于三者。  
> 每条按「时机 + 动作」写，一行一条。

## 一、每帧顺序

1. 采样世界：探地面、探墙，踩地时贴地吸附并清零 vy。
2. BeginStep：读真值并剥掉外部速度，清空增量，速度乘数复位，外部速度衰减一次。
3. 姿态机：定下本帧能否跳/冲、身高倍率与 View 目标值。
4. 移动机：先判抢占（冲刺优先于跳），再判状态是否结束。
5. 状态 Tick：提交本帧的水平逼近与重力设定。
6. 攻击机：排在移动机之后，开火那一帧生成子弹并叠加一份反向外部速度（后坐力）。
7. 充能计时：读本帧的冲刺起手，蓄满转待释放；冲刺起手时请求残影系统落影。
8. ApplyGravity：施加当前重力，钳制上升与下落速度。
9. Commit：有提交或外部速度在变才写回，写的是「常规速度 + 外部速度」。
10. 渲染帧：把姿态给的缩放落到 View，以脚底为锚点。

- 过门请求插在 BeginStep 之后：TransitMotor 先换输入，再进姿态与移动。
- 姿态看到的是替换后的输入：下蹲键为假，蹲姿会按起身判定切回。
- 残影系统排在玩家之后：CombatRoot 在同一物理帧里推进 AfterimageLogic（清过期）并刷新 AfterimageField。

## 二、移动机的抢占与回落

- 抢占顺序固定：先判冲刺，再判跳跃（地面跳 / 空中跳）。
- 抢占必须成功消费对应输入，否则本次抢占作废。
- 目标与当前状态相同则不切换，直接继续 Tick。
- 当前状态 IsDone 后，按基础态规则回落。
- 基础态：离地且帧首 vy>0 → Jump，否则 → Fall。
- 基础态：踩地且有水平输入 → Move，否则 → Idle。
- 落地那一帧：清土狼消耗、空中跳次数、空中冲刺次数。

## 三、Idle 地面待机

- 进入：踩地且无水平输入（落地后或松键后）。
- 物理：每帧按 moveDeceleration 把 vx 收敛到 0。
- 物理：踩地且 vy≤0 时 vy 钳为 0，贴地不下沉。
- 退出：有水平输入 → Move；离地 → 按 vy 分 Jump / Fall。

## 四、Move 地面行走

- 进入：踩地且有水平输入。
- 物理：同向时按 moveAcceleration 逼近 ±moveSpeed。
- 物理：反向输入按 turnAcceleration，过 0 后换回 moveAcceleration。
- 物理：目标速度再乘姿态的移速乘数（下蹲时 0.5）。
- 退出：水平输入归零 → Idle；离地 → 按 vy 分 Jump / Fall。

## 五、Jump 地面跳上升期

- 进入：踩地，或离地仍在 coyoteTime 内且未消耗。
- 进入：跳键需在 inputBufferTime 内，冲刺中按跳无效。
- 进入：下蹲且 crouchAllowJump 关时不给跳，也不消费输入。
- 起跳帧：vy 直接写为 jumpSpeed，重力设为 riseGravity。
- 起跳帧：若已松键，立刻按 Jump Cut 截断一次。
- 上升期，松开跳跃键时，vy 乘 jumpCutMultiplier，重力改 jumpCutGravity。
- 上升期，按住跳且 0<vy<apexThreshold，重力改 apexGravity。
- 物理：水平按 Move 规则逼近，vy 只受重力与上限钳制。
- 退出：帧首 vy≤0 → Fall，并把重力设为 fallGravity。
- 补充：上升中被重新归入本态时不重复给速度。

## 六、AirJump 空中跳上升期

- 进入：离地，且土狼机会已用掉或已过期。
- 进入：剩余 maxAirJumps 次数 >0，跳键在缓冲窗口内。
- 进入：冲刺中或下蹲禁用跳跃时，同样不给。
- 起跳帧：vy 直接覆盖为 airJumpSpeed，重力设为 riseGravity。
- 物理：水平逼近、顶点悬停、松键截断都与 Jump 一致。
- 次数：每次成功起跳扣 1 次，落地那一帧回满。
- 退出：帧首 vy≤0 → Fall，并把重力设为 fallGravity。
- 现状：maxAirJumps 配 0，本态目前不可达。

## 七、Fall 下落期

- 进入：离地且帧首 vy≤0。
- 物理：有输入按 Move 规则逼近，无输入按 moveDeceleration 归零。
- 物理：重力恒为 fallGravity，vy 下限为 -maxFallSpeed。
- 退出：踩地后按有无水平输入切 Move 或 Idle。

## 八、Dash 冲刺

- 进入：冷却结束，冲键在 dashBufferTime 窗口内。
- 进入：踩地可直接冲，空中需 maxAirDashes 次数未用完。
- 进入：下蹲且 crouchAllowDash 关时不给冲，也不消费输入。
- 物理：进入时关闭重力，速度覆盖为 朝向×dashSpeed，vy 归零。
- 物理：持续期间不响应左右输入，也不能起跳。
- 退出：超过 dashDuration → 恢复重力，再按 vy 分 Jump / Fall。
- 次数：离地触发才扣空中冲刺次数，落地回满。

## 九、姿态机的切换

- 基础态是 Stand，IsDone 恒 false，只能被抢占切走。
- 踩地、按住 S、且不在"待松手"状态 → 进下蹲，空中不给蹲。
- crouchPrepareTime>0 进前摇，=0 直接进 Crouch。
- 蹲姿起身要两个条件：松开 S，且头顶有站直空间。
- 前摇中不判起身，自己走完或被打断，抢占不插手。
- 被打断后要求先松开 S，否则按住会立刻被拖回前摇。
- 蹲姿与前摇的离地判定走 crouchGroundGrace 宽限，不读原始踩地。

## 十、Stand 站立

- 进入：初始帧，或前摇结束/被打断后回到本态。
- 物理：身高与移速乘数都是 1，不限制跳跃与冲刺。
- 退出：无（IsDone 恒 false），只能由抢占切走。

## 十一、CrouchingTransition 下蹲前摇

- 进入：踩地且按住 S，crouchPrepareTime>0；空中进不来。
- 物理：身高倍率与移速乘数按同一条曲线推向蹲姿值。
- 物理：进度 = 已用时间 / crouchPrepareTime，封顶 1。
- 限制：进度未满仍可跳可冲，满的那一帧起开始限制。
- 打断：松开 S、离地超 crouchGroundGrace、外部 InterruptToStand。
- 打断物理：Exit 只回身高，移速乘数下一帧帧首才复位。
- 退出：进度满 → Crouch；被打断 → Stand。

## 十二、Crouch 完全蹲下

- 进入：踩地，前摇走完；或前摇配 0 时按住 S 直接进来。
- 物理：身高压到 crouchHeightRatio，碰撞体与墙探针同步。
- 物理：每帧重报移速乘数 crouchMoveSpeedScale，帧首会复位。
- 限制：crouchAllowJump / crouchAllowDash 关时禁跳禁冲。
- 限制：禁令不消费输入，起身后缓冲窗口内仍会生效。
- 退出：离地超 crouchGroundGrace → Stand，这是本态唯一的自结束。
- 退出：松开 S 且头顶有空间时，由抢占切回 Stand。
- 起身探测：从蹲头顶向上扫到站头顶，触发器不算阻挡。

## 十三、姿态与移动的三条硬约束

- 姿态必须先于移动推进，否则按下蹲键那帧还能跳。
- 移速乘数是一次性的，姿态每帧都要重新提交。
- 身高只改碰撞体 size/offset，不压 transform.scale。

## 十四、重力与贴地

- 踩地且 vy≤0：钳为 0，不累积重力。
- 踩地时表现层先贴地并清零 vy，逻辑层只读结果。
- 其余情况：vy 每帧减去当前重力 × Δt。
- 速度钳制：上升上限 maxRiseSpeed，下落下限 maxFallSpeed。
- 重力来源：起跳写 riseGravity，顶点写 apexGravity。
- 重力来源：松键写 jumpCutGravity，跳跃结束写 fallGravity。
- moveAcceleration≤0 时，所有水平动作都当帧直达。

## 十五、外部速度修正

- 速度记两份：常规移动速度由 MoveGroup 各态提交，外部速度由 AddExternalVelocity 叠加。
- 移动状态只读写常规部分，覆盖不到外部部分；外部速度也不参与水平速度的逼近。
- 每帧帧首按 externalDeceleration × Δt 把外部速度朝 0 线性衰减，不会越过 0 反向。
- 帧首读刚体后先减去上帧写进去的外部速度，状态看到的始终只有常规速度。
- Commit 写回刚体的是「常规速度 + 外部速度」，所以移动状态改不到最终速度。
- 外部速度即使没有常规提交也要写回，否则衰减落不到刚体上，角色会一直被推着走。
- 撞墙、落地把速度清零时，外部冲量判定为已被物理消耗，不会剥成一份反向的常规速度。
- 瞬移（SpawnAt）会清空外部速度，旧冲量不会带到新位置。
- 后坐力：开火帧沿弹道反方向叠加一份外部速度，平射 / 斜上 / 斜下各读一份参数。

## 十六、攻击状态组（白）

- 与移动、姿态完全正交：不改移动状态，也不读姿态禁令。
- 基础态是 None，IsDone 恒 false，只能被抢占切走。
- 抢占条件：当前为 None、攻击键本帧按下沿、attackCooldown 已过。
- 冷却从触发攻击那一帧起算，不是从开火那一帧起算。
- attackPrepareTime>0 进前摇，=0 当帧直接进 WhiteAttack。
- 前摇只计时，不缓存攻击键；期间不响应新的攻击输入。
- WhiteAttack 是开火那一帧：Enter 里生成子弹并写后坐力，只停留一帧。
- 弹道：起点取 WorldInfo.Pos，水平分量取 WorldInfo.Face。
- 弹道：Move.y>0.5 算斜上 45°，<-0.5 算斜下 45°，否则平射。
- 阈值 0.5 吸收摇杆漂移，取的是开火那一帧的 Move.y。
- 朝向没定过时退回缩放方向，默认朝右。
- 后坐力沿弹道反向叠加，走外部速度并自行衰减。
- 平射读 recoilSpeedX，斜上读 recoilSpeedUp，斜下读 recoilSpeedDown。
- 蹲姿倍率 crouchRecoilScale 乘在上述三项之后，按 PostureGroup.CrouchProgress 从 1 线性插值：
  半蹲取中间值，蹲满才是设定倍率；空中不给蹲，所以空中开火恒为站立倍率。
- attackRecoverTime>0 进后摇，=0 直接回 None；后摇期间同样不响应攻击输入。
- 后摇走完回 None，下一次攻击仍要过 attackCooldown。
- 攻击机排在移动机之后：开火方向要用本帧 MoveState 刚写入的朝向，后坐力则不再依赖帧序。

## 十七、充能与残影（PlayerLogic + AfterimageLogic）

- 充能**不是状态组**：没有基础态、没有抢占，只有 PlayerLogic 里的一个计时器。
- 计时器插在攻击组之后；排在此处是因为它要读本帧的冲刺起手。
- 三阶段：None（空闲）、Charging（前摇）、Charged（蓄满待释放）。
- 起蓄条件：当前为 None、充能键**按下沿**、chargeCooldown 已过。
- 充能键是「按一下」触发，不需要按住；松手不会取消。
- chargePrepareTime>0 进 Charging 计时，=0 按下当帧直接 Charged。
- 前摇走满转 Charged 并调 IAfterimageSpawner.Arm()，不会自己回落，一直保持到冲刺释放。
- 冲刺起手那一帧 PlayerLogic 调 IAfterimageSpawner.TrySpawn(位置, 时间)，生不生成由残影系统判断。
- TrySpawn 只在已 Arm 且名额可用时返回 true；返回 true 才起 chargeCooldown 并回 None。
- 冲刺起手判定：移动机推进前后的标签由非 Dash 变 Dash 的那一帧。
- 前摇没走完就冲刺：这次冲刺不落影，充能继续进行，不算浪费。
- 冷却从落影那一刻起算，不是从按键起算；冷却中按键完全无效。
- 充能计时的代码在 `Logic/Actor/Player/PlayerLogic.cs`，ChargePhase 是同目录的独立枚举。
- AfterimageLogic 持有并驱动账本：落影、上限顶替、过期清理、连线判定都在它这里。
- AfterimageLedger 退化为纯数据：只按生成顺序存 Afterimage，暴露 Count 与索引器。
- 残影只记位置、落地时刻与生成序号，由 AfterimageLedger 统一记账。
- 残影到 afterimageDuration 自动过期，按生成顺序从最早一枚开始清。
- 场上满 maxAfterimages 时顶掉最早的一枚，不拒绝放置。
- 连线取生成顺序相邻的两枚，末枚接回首枚；两枚时只有一条。
- 相邻两枚间距超 afterimageLinkSenseRadius 时不连线，避免跨图拉超长线。
- 连线判定是一根绕中点旋转的方块：长取间距，宽取 afterimageLinkThickness。
- 连线平时只是画出来的线，**不结算持续伤害**；只有子弹正沿着某条连线传输时才结算。
- 跨场景与重生都走 SpawnTo，它调用 IAfterimageSpawner.Clear() 清账本与待释放状态。
- 表现层 AfterimageField 由 CombatRoot 创建成自己的子物体，不挂在玩家身上：玩家重生或销毁都不影响场上残影，也不写进 Player.prefab。
- 表现层残影是冲刺那一刻 View 的定妆克隆：行为与碰撞体一律关掉，落影帧拍一次姿态后就固定。
- 槽位按残影序号绑定，不按队列位置：最老一枚过期时不会把还活着的残影重拍成现在的样子。
- 残影体走 Foundation 的 Pool<Slot>：容量取 maxAfterimages 并预先造好，过期回收进池复用。
- 残影随时间从 afterimageAlpha 线性淡到写死的终止透明度（0.12），最后一秒按 6Hz 闪烁。
- 淡出与闪烁的三个常量写在 AfterimageField 里，先不开放成配置。

## 十八、子弹在残影间传输

- 残影外壳是 Resources/Prefabs/AfterImage：Collider 子物体就是吸引子弹的判定范围，View 子物体是玩家 View 的运行时副本。
- 子弹只有两个状态：Flying（靠刚体速度直线飞）与 Transporting（关掉碰撞、按路径逐段位移）。
- 进入第一枚残影时当场算完 TransferPlan 并锁定：从入口按生成顺序往后走，绕到入口那一格为止。
- 相邻两枚的间距超过 afterimageLinkSenseRadius 就不再往下走，路径停在当前这一枚。
- 每一段出发前都回残影系统验活：目标被顶掉或过期就立刻终止传输，在当前有效位置恢复飞行。
- 传输速度取 bulletTransferSpeed，0 表示瞬移到下一枚。
- 传输途中不结算伤害也不吃碰撞；出射时碰撞体刚恢复会重复触发一次进入，靠子弹自己的「已传输」标记挡掉。
- 一颗子弹只被接管一次：出射后标记作废，之后飞回任何残影都不再进入传输，避免在两枚残影之间来回弹成死循环。
- 出射方向：水平分量取残影朝向，垂直分量沿用进入时的飞行方向。
- 出射后恢复 Dynamic 与 bulletSpeed，和普通子弹一样结算伤害。
- 只传输玩家自己发出的子弹：按开火者与残影的 playerRoot 比对。
- 路径至少得有一跳（入口加下一枚）：场上只有一枚残影时不接管子弹，子弹按原轨迹直接飞过去。
- 子弹每走一段，都通过残影身上的 AfterimageAnchor 拿到 AfterimageField，报告 BeginTraverse(起点序号, 终点序号)。
- 被穿的那条连线在传输期间变成不透明（alpha 取 1），走完这一段或被中断就恢复 afterimageLinkColor 的透明度。
- 同一条连线可能同时有几颗子弹在走，热度按次数叠加，走完一颗只减一次，全走完才恢复。
- 沿线伤害在这个 BeginTraverse 时刻结算**一次**：判定方块与画出来的线完全重合，同一次结算里同一个受击盒只吃一刀。
- 结算不受传输速度影响，也和子弹是否真的走到终点无关：一进这段线就结算。
- 子弹的逻辑在 `Logic/Combat/Bullet/BulletLogic`（实现 IBulletLauncher），表现外壳是 `Presentation/Combat/Bullet/Bullet`，由 `BulletField` 造。
- 子弹外壳走 Foundation 的 Pool<Bullet>：上限 32、预热 8，CreateOrDrop 策略；取用时 SetActive(true)，回收时 Reset + SetActive(false)，不 Destroy。
- 伤害由子弹自己身上的 AttackBox 结算：Bind 里 SetAttack(this)，结算成功（血量真的掉了）回调 OnHitLanded，立刻把这一发还池。
- 一发子弹只对一个敌人结算一次：OnHitLanded 先判「已结算」标记，回收时再摘掉 AttackBox 的攻击者，同帧剩下的受击盒回调全部空转。
- 撞到敌人层时 Bullet 不自己收池，交给 AttackBox 结算：池化后 SetActive(false) 会当场掐断碰撞，先收就把这一枪吞了。
- 残影逻辑在 `Logic/Combat/Afterimage`，残影与连线的表现是 `Presentation/Combat/Afterimage`。
- `CombatRoot` 在物理帧统一 Tick 子弹逻辑，`Bullet` 自己不注册场景根、不写 Update：它只把姿势落到刚体与碰撞体上，并把触发器回调转给逻辑层。

## 十九、状态流转图

```text
移动：Idle ⇄ Move
Idle/Move --离地--> Jump(vy>0) 或 Fall(vy≤0)
Jump/AirJump --vy≤0--> Fall
Fall --落地--> Idle 或 Move
任意状态 --冲刺键--> Dash --时长到--> 按 vy 回落

姿态：Stand --踩地且按住S--> 前摇(>0) 或 Crouch(=0)    （空中进不来）
前摇 --进度满--> Crouch
前摇 --松键/离地超限/外部打断--> Stand
Crouch --松键且头顶有空间--> Stand
Crouch --离地超 crouchGroundGrace--> Stand

攻击：None --攻击键且冷却过--> 前摇(>0) 或 WhiteAttack(=0)
前摇 --attackPrepareTime 到--> WhiteAttack --开火--> 后摇(>0) 或 None(=0)
后摇 --attackRecoverTime 到--> None

充能：None --充能键按下沿且冷却过--> Charging(>0) 或 Charged(=0 当帧)
```

## 附注

- 掉出世界（y 低于 \_spawnY）时回到最近一次踩地的位置。
- 姿态的第一帧 Current 为 None，按站姿算，同帧即可进蹲。
- 姿态与踩地是耦合的：进蹲要真踩地，蹲住后靠 crouchGroundGrace 容忍掉帧。
- 进蹲看原始踩地，蹲姿/前摇看宽限：两者不同源，别把 CanCrouch 也换成宽限。
- InterruptCrouch 已暴露到 PlayerLogic，但目前没有任何调用方。
- 离开蹲姿那一帧仍沿用上一帧的移速乘数，下一帧帧首才复位。
- 贴地吸附与探测参数在 PlayerMotor，不在 PlayerConfig（MoveMotor 只管刚体与速度账本）。
- 子弹预制体由 CombatRoot 指定，留空则懒加载 Resources/Prefabs/Bullet；Bullet 在 Bind 时补 Rigidbody2D（只补一次，之后池里复用）并记住自己的伤害。
- 子弹靠刚体速度飞行；传输段由 BulletLogic 逐段摆位，两者都在 CombatRoot 的物理帧里推，Bullet 不写 Update。
- Bound 只在 Level_1 接进 Bound 层，其余关卡还在 Default：那几关的子弹飞出地图不会回池，只能靠撞 Ground 或命中敌人收掉。
- 下蹲时的独立弹道尚未实现，子弹仍从玩家中心（站立枢轴）射出。
- 充能键绑在 O（InputSys.inputactions 新增的 Charge 动作，手柄西键）；生成物要等编辑器重导入后才带该属性，
  所以 InputProvider 按名字 FindAction("Charge")，找不到只报一次警告，不影响编译。
- 残影落点是世界坐标：账本里的 Pos 加「落影帧 View 相对玩家枢轴的偏移」，参照系是玩家枢轴，不是 AfterimageField 自己的 Transform。
- 残影槽位挂在 CombatRoot 的容器下，缩放要除掉容器继承来的那一层，否则会被放大两次。
- 残影与连线的表现挂在 AfterimageField：由 CombatRoot 在 Attach 时创建为自身子物体并每物理帧驱动。
- 连线用运行时生成的 1×1 白图按 1 像素 = 1 米拉伸，不依赖美术给方形图。
- 蓄满贴图不用限时：Charged 是个持续状态，冲刺释放前一直挂着那张图。
- 充能配色写死在 PlayerController（黄 → 橙），配置里只留两张贴图，避免美术换色还要改资产。
- 残影快照里的颜色与贴图取的是落影那一帧 View 的样子，之后本体换装不影响已落下的残影。
