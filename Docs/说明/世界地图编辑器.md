# 世界地图编辑器（第四阶段）

代码在 `Assets/Editor/MapEditor/WorldMap/`，数据默认在 `Assets/MapEditorData/WorldMaps/`。
单关卡编辑仍由 `Assets/Editor/MapEditor/` 原有模块负责，世界地图只引用关卡资产，不复制地图纹理。

## 一、范围

**做**：多关卡自由摆放 / 拖动 / 网格吸附 / 锁定、关卡连接线、独立 PNG 导出、世界地图资产保存重开恢复。
**暂不做**（本次明确跳过）：入口 / 出口 / 传送点 / Boss 等 `MapMarker` 标记（4.4）。
单关卡地图的扫描、绘制、擦除、撤销重做仍走原有的 Map Editor，不在世界地图窗口里改。

## 二、文件结构

| `Data/WorldMapData.cs` | 世界地图 SO：`mapName`、`levels`、`connections` | — |
| `Data/LevelMapPlacement.cs` | 单关摆放：`sceneGuid`、`position`、`locked` | — |
| `Data/MapConnection.cs` | 连接：`fromSceneGuid` / `toSceneGuid` + 各自局部锚点 | — |
| `Canvas/WorldMapCanvas.cs` | 输入分发、选择 / 拖动状态、合成纹理缓存、Fit | `HandleInput` / `Draw` / `Fit` |
| `Canvas/WorldMapRenderer.cs` | 坐标转换、包围盒、命中测试、分层绘制 | `Bounds` / `HitPlacement` / `HitConnection` |
| `Tools/SelectTool.cs` | 工具接口 / 上下文 / 选择拖动（含吸附、锁定） | `OnDown` / `OnDrag` |

## 三、数据模型

- `WorldMapData` 是独立 `ScriptableObject`（`CreateAssetMenu: Refraction/World Map`），只存关卡 GUID、位置、连接；
  关卡内容仍来自 `MapDataManager.Load(sceneGuid)`，所以单关地图修改后世界地图能读到最新纹理。
- `LevelMapPlacement.position` 是**世界坐标（单位：Unity Unit，y 向上）**；地图显示尺寸 = 纹理像素 / 关卡 `pixelsPerUnit`。
- `MapConnection.fromPosition` / `toPosition` 是**关卡局部坐标**（相对 `placement.position`，默认取关卡中心），
  因此关卡移动后连接线自动跟随。
- 本次没有 `MapMarker` / `MapMarkerType`，也没有标记绘制 / 导出。

## 四、交互

- 打开：`Tools ▸ Refraction ▸ World Map Editor`；自动记住上次打开的世界地图（EditorPrefs）。
- 世界地图：工具栏对象栏选择已有资产，或点「新建」在 `Assets/MapEditorData/WorldMaps/` 创建；「保存」/ `Ctrl+S` 写盘。
- 左侧关卡列表：点 `+` 把关卡加入世界地图（同一 GUID 不可重复）。
- 工具：
  - **Select**：点关卡选中并显示黄框；未锁定时左键拖动，`吸附` 开启时按 1 Unit 取整；点连接线选中（蓝色）。
  - **Connection**：依次点两个关卡建立直线连接；再次点同一关取消。
  - **Hand**：左键拖动平移；中键或 `Space + 左键` 在任意工具下平移。
- 滚轮以鼠标为中心缩放；`F` 适应画布；`Delete` / `Backspace` 删除选中的关卡摆放或连接。
- 右侧检查器：改位置、锁定 / 解锁、移出世界地图、删除连接，以及导出设置。

## 五、导出

`WorldMapExporter.Export(data, settings)` 独立计算世界包围盒（每边 Padding 1 Unit）并合成纹理：

1. 按 `pixelsPerUnit × scale` 把世界尺寸换成像素尺寸（上限 8192）。
2. 透明背景或指定背景色填充。
3. 可选网格（1 Unit 一格）、可选连接线（青色直线）。
4. 逐关卡取 `MapCompositor.CreateComposite`（含 Ground 底图、手绘层与双遮罩合成）并最近邻缩放写入。
5. `Texture2D` 返回，窗口写 PNG 并以 Point / 无 mipmap / alphaIsTransparency 导入。

导出**不包含**编辑器 UI、画布平移缩放、画布空白区，也不包含标记（本次未实现）。

## 六、不变式

1. 世界地图不复制关卡纹理，只按 GUID 引用；关卡 GUID 是唯一关联键。
2. 拖动只改 `LevelMapPlacement.position`，不改 `LevelMapData`，不改 Scene。
3. 连接线端点存关卡局部坐标，移动关卡后必须跟随。
4. 锁定关卡不可拖动；删除关卡摆放要同时删掉相关连接。
5. 合成纹理按关卡底图引用 / `isDirty` 变化重建，避免每帧 `CreateComposite`。
6. 导出尺寸只由世界包围盒和导出设置决定，与 EditorWindow 当前缩放 / 尺寸无关。
7. `.meta` 一律由 Unity 生成，AI 不写；本模块为 Editor 代码，改动仍尽量精简。
