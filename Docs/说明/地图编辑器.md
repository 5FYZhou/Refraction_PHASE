# 地图编辑器（Map Editor）

> 依据代码：`Assets/Editor/MapEditor/**`（28 个 .cs，命名空间 `Refraction.MapEditor`），
> 数据落在 `Assets/MapEditorData/**`。文档是快照，与代码冲突时以代码为准。
> 目标：扫描关卡 Scene 的 `Ground` 生成单关底图，在独立窗口里画 / 擦 / 平移缩放 / 撤销重做 /
> 自动保存，重开恢复；Ground 源数据变化时给出三档处理。

## 一、范围

**做**：`Level_正整数` 场景扫描 → 递归读 `Ground` 下 SpriteRenderer（含隐藏）→ 四角点转相对坐标 →
白色地面底图 → IMGUI 画布编辑 → 每关数据独立落盘 → 源变化检测与重扫合并。

**不做**：世界地图拼接、关卡连接线、入口出口图标、原始 Sprite 纹理模式、复杂材质 / Shader、
Sliced / Tiled SpriteRenderer。撤销历史**不跨 Unity 重启**（按计划，只保证编辑结果持久化）。

## 三、数据

### 3.1 `LevelMapData`（v2）

| 分组 | 字段 |
|---|---|
| 源数据 | `sceneGuid`（主键）、`sceneName`、`sourceBounds`、`pixelsPerUnit`、`sourceSprites`、`groundHash` |
| 生成数据 | `groundTexture`、`groundEraseMask` |
| 编辑数据 | `paintTexture`、`paintEraseMask`、`groundColor`、`backgroundColor`、`isDirty` |
| 版本 | `dataVersion = 2` |

v1 → v2：`mapBounds` → `sourceBounds`、`sprites` → `sourceSprites`、`eraseMask` → `groundEraseMask`
（用 `[FormerlySerializedAs]` 保留旧资产引用），新增 `paintEraseMask`。首次加载自动迁移。

`MapSpriteData` 除 `hierarchyPath` 与四角点外，还存 `spriteGuid` / `localFileId` / `localPosition` /
`localRotation` / `localScale` / `color` / `flipX` / `flipY`，供变化检测用。

### 3.2 三层合成

```
Final = (Ground · groundColor · (1 - Mg)) + (Paint · (1 - Mp))
```

- **Mg = groundEraseMask.alpha**：橡皮挖掉原始 Ground。
- **Mp = paintEraseMask.alpha**：画笔绘制时清 0（让 Paint 显示），橡皮擦除时写 1。
- 两层遮罩独立，原始地形与手绘内容可各自擦除而不互相污染。
- 合成纹理 `_composite` 只在切关 / 尺寸变化时重建，其余复用；绘制时仅重算脏区，不落盘。

### 3.3 落盘

```
Assets/MapEditorData/Levels/Level_<n>.asset
Assets/MapEditorData/Textures/Level_<n>/Ground.png
Assets/MapEditorData/Textures/Level_<n>/GroundEraseMask.png
Assets/MapEditorData/Textures/Level_<n>/Paint.png
Assets/MapEditorData/Textures/Level_<n>/PaintEraseMask.png
```

PNG 写临时文件 → 删旧 → 移动 → 导入（Point / 可读 / 无 mipmap / alphaIsTransparency）。
`Load` 按 `sceneGuid` 查，不用关卡名做主键。

## 四、坐标与交互

地图坐标 = 纹理像素（左下原点，Y 向上）；屏幕坐标 = 画布局部（左上原点，Y 向下）。
`CanvasTransform.ScreenToMap` 里做 Y 翻转，缩放以鼠标位置为锚点，范围 0.05–20，F 或按钮适应视图。

- **Brush / Eraser**：左键。`DrawLine` / `EraseLine` 在上一采样点与当前点间插值（步长 `radius/2`），
  快速拖动不断笔。
- **Hand**：左键拖动平移；另有中键拖动、Space + 左键拖动，两种与工具无关。
- **笔刷预览**：单独用 `Handles.DrawWireDisc` 画圈，不改地图数据。
- **网格**：按 `pixelsPerUnit × zoom` 步进，随缩放变化。

## 五、撤销 / 重做与保存

- `IMapCommand` 用 `Dictionary<Texture2D, Dictionary<int, PixelEdit>>` 记录受影响像素：
  同像素只留**最初 before / 最终 after**，`HasChanges` 提交时剔除改回原值的无效记录；一笔拖动 = 一条命令。
- `MapHistory` 最多 50 步，`Push` 截断重做分支；`Undo` / `Redo` 只改内存纹理。
- 自动保存：`MarkDirty` 进待保存表，`EditorApplication.update` 里空闲 1 秒写盘；
  切关立即保存、关窗 / 退出 Flush、Ctrl+S 立即保存、另有「保存全部」。
- 撤销历史不持久化，重开窗口后不可跨会话撤销。

## 六、源变化检测与重扫

`GroundScanner` 采集每个 Sprite 的 GUID / localFileId / 局部变换 / 颜色 / flip / 四角点；
`GroundHashCalculator` 按 `hierarchyPath` 稳定排序后算总 MD5，存进 `groundHash`。

扫描时若 `groundHash` 变化，弹三档对话框：

1. **重新生成底图** — 保留 Paint / 两个遮罩，按局部坐标重映射到新边界（含 PPU 变化）。
2. **保留当前地图** — 不更新底图。
3. **重建全部数据** — 二次确认后清空全部人工编辑（等同「重建」按钮）。

边界变化重映射走 `Pixel_old / PPU_old + Origin_old → (P_old - Origin_new) × PPU_new`；
源纹理缺失或旧边界无效时拒绝覆盖并告警，不写半套数据。

## 七、不变式

1. 不静默切场景：扫描 / 重建前 `SaveCurrentModifiedScenesIfUserWantsTo`，结束恢复原场景。
2. `Ground` 必须是场景根对象且名字恰好 `Ground`。
3. 旋转 Sprite 不能画成轴对齐方块：`FillConvexQuad` 逐像素内点测试。
4. 扫描保绘制、重建清绘制；两者互不替代，别把清空逻辑塞进 `Scan`。
5. `sceneGuid` 是主关联键，关卡改名 / 挪位不丢数据。
6. 地图坐标与画布坐标彻底分离：缩放 / 平移只改显示，不改 `sourceBounds` 与纹理。
7. `.meta` 一律由 Unity 生成，AI 不写；editor 目录不受 `comment-lint` 覆盖，改动仍尽量精简。
8. 绘制路径只做区域读写：Brush / Eraser 用 `GetPixels(x,y,w,h)` / `SetPixels(x,y,w,h)`，
   每个插值圆 **不 Apply**，只在 MouseUp 由 `PixelCommand.ApplyTextures` 统一 Apply。
9. 合成纹理 `_composite` 由 `MapCanvas` 持有，切关 / 关窗时 `Release`；禁止每帧 `CreateComposite`。
   脏区为空（Undo / Redo / 切关）才全图合成。
