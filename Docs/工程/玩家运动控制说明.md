# 玩家运动控制说明

> 依据当前代码整理：MoveGroup、PostureGroup 与八个状态类、MoveLedger。  
> 每条按「时机 + 动作」写，一行一条。

## 一、每帧执行顺序

1. 采样世界：探地面、探墙，读帧首速度与朝向；踩地时把刚体贴回地面（贴地吸附）。
2. BeginStep：记录帧首速度，清空本帧的速度增量，速度乘数复位成 1。
3. 姿态：PostureGroup 先推进，定下这一帧是站立还是下蹲（顺带压碰撞体、压移速、改 View 缩放）。
4. 移动状态机：先判抢占（冲刺优先于跳），再判当前状态是否结束。
5. 状态 Tick：提交本帧的水平逼近与重力设定。
6. ApplyGravity：施加当前重力，并钳制上升/下落速度。
7. Commit：本帧有提交才把速度一次性写回刚体。
8. 应用 View 缩放：PlayerController 把逻辑层给的缩放落到 View 上。

> 姿态必须排在移动之前：下蹲会禁跳、禁冲，晚一步就会有一帧"已经蹲下了还能跳"。

## 二、抢占与回落规则

- 抢占顺序固定：先判冲刺，再判跳跃（含空中跳）。
- 抢占必须同时成功消费对应输入，否则本次抢占作废。
- 抢占目标与当前状态相同则不切换，直接继续 Tick。
- 当前状态 IsDone 时按基础态规则回落。
- 基础态：离地且帧首 vy>0 → Jump，否则 → Fall。
- 基础态：踩地且有水平输入 → Move，否则 → Idle。
- 落地那一帧：恢复土狼机会、空中跳次数、空中冲刺次数。

```
Idle ⇄ Move
Idle / Move --离地--> Jump(vy>0) 或 Fall(vy≤0)
Jump / AirJump --vy≤0--> Fall
Fall --落地--> Idle 或 Move
任意状态 --冲刺键--> Dash --时长到--> 按 vy 回落
Stand --踩地按住 S--> CrouchingTransition --前摇走完--> Crouch
CrouchingTransition --松键 / 离地 / 被外部打断--> Stand（移速与缩放瞬间恢复）
Crouch --松开 S 且头顶有空间--> Stand
Crouch --离地--> Stand（落地按住 S 会重新蹲下）
```

## 三、Idle 地面待机

- 进入：踩地且无水平输入（落地后或松键后）。
- 物理：每帧按 moveDeceleration 把 vx 收敛到 0。
- 物理：踩地且 vy≤0 时 vy 被钳为 0，贴地不下沉。
- 物理：踩地时刚体被吸附到地面上（脚底留 groundSkin 间隙），站立高度与落地方式无关。
- 退出：有水平输入 → Move；离地 → 按 vy 分 Jump / Fall。

## 四、Move 地面行走

- 进入：踩地且有水平输入。
- 物理：同向时按 moveAcceleration 逼近 ±moveSpeed。
- 物理：反向输入时按 turnAcceleration，过 0 后换回 moveAcceleration。
- 退出：水平输入归零 → Idle；离地 → 按 vy 分 Jump / Fall。

## 五、Jump 地面跳上升期

- 进入：踩地，或离地仍在 coyoteTime 内且未消耗。
- 进入：跳键需在 inputBufferTime 窗口内，冲刺中按跳无效。
- 起跳帧：vy 直接写为 jumpSpeed，重力设为 riseGravity。
- 起跳帧：若已松键，立刻按 Jump Cut 截断一次。
- 上升期，松开跳跃键时，vy 乘 jumpCutMultiplier，重力改 jumpCutGravity。
- 上升期，按住跳且 0<vy<apexThreshold 时，重力改 apexGravity。
- 物理：水平仍按 Move 规则逼近，vy 只受重力与上限钳制。
- 退出：帧首 vy≤0 → Fall，并把重力设为 fallGravity。
- 补充：上升途中被重新归入本态时不重复给速度。

## 六、AirJump 空中跳上升期

- 进入：离地，且土狼机会已用掉或已过期。
- 进入：剩余 maxAirJumps 次数 >0，且跳键在输入缓冲窗口内。
- 起跳帧：vy 直接覆盖为 airJumpSpeed，重力设为 riseGravity。
- 物理：水平逼近、顶点悬停、松键截断都与 Jump 完全一致。
- 次数：每次成功起跳扣 1 次，落地那一帧回满。
- 退出：帧首 vy≤0 → Fall，并把重力设为 fallGravity。

## 七、Fall 下落期

- 进入：离地且帧首 vy≤0。
- 物理：有输入按 Move 规则逼近，无输入按 moveDeceleration 归零。
- 物理：重力恒为 fallGravity，vy 下限为 -maxFallSpeed。
- 退出：踩地后按有无水平输入切 Move 或 Idle。

## 八、Dash 冲刺

- 进入：冷却结束，且冲刺键在 dashBufferTime 窗口内。
- 进入：踩地可直接冲，空中需 maxAirDashes 次数未用完。
- 物理：进入时关闭重力，速度覆盖为 朝向×dashSpeed，vy 归零。
- 物理：持续期间不响应左右输入，也不能起跳。
- 退出：超过 dashDuration → 恢复重力，再按 vy 分 Jump / Fall。
- 次数：离地触发才扣空中冲刺次数，落地回满。

## 九、姿态：Stand / CrouchingTransition / Crouch

- 姿态是独立于移动的一组状态，由 PostureGroup 驱动，每帧排在移动之前。
- 三个状态：Stand（站立）、CrouchingTransition（前摇，过渡中）、Crouch（已完全蹲下）。
- 进入前摇：踩地且按住下蹲键（默认 S）。crouchPrepareTime > 0 走前摇，= 0 直接进 Crouch（省掉一帧半蹲）。
- 前摇期间：身体高度与移速乘数按**同一条线性曲线**从站姿值过渡到蹲姿值，进度 = 已用时间 / crouchPrepareTime。
  View 缩放用同一个进度，和碰撞体高度严格同步，不会出现"人矮了图还高"。
- 前摇期间不限跳、不限冲：此时人被卡住会很怪，要中断直接起跳走人即可。
- 前摇结束：进 Crouch，跳跃/冲刺限制从这一帧起生效。
- 前摇被打断：松键、离地、或外部调用 `PostureGroup.InterruptToStand(ctx)`，一律立刻回 Stand，
  移速乘数与身体/View 缩放**瞬间恢复**到站姿（不做回弹过渡，也不做头顶空间检查）。
- 打断后要求松手下蹲键才能重新蹲（`_needReleaseToCrouch`），否则按住 S 的玩家下一帧又会被拖回前摇。
- 移速：crouchMoveSpeedScale 乘在 moveSpeed 上，走 MoveLedger 的速度乘数（SetSpeedScaleX）。
  乘数是**一次性**的，帧首复位，所以前摇与 Crouch 每帧都要重新提交；MoveState 不知道下蹲。
- 限跳：crouchAllowJump 默认关，地面跳、土狼跳、空中跳一并被挡。
- 限冲：crouchAllowDash 默认关，地面冲与空中冲一并被挡。
- 挡下时**不消费输入**：起身后在 inputBufferTime / dashBufferTime 窗口内按的跳和冲仍会生效。
- 退出 Crouch：松开下蹲键，且头顶有空间；离地也直接结束，空中不给蹲。
- 离地宽限：前摇与 Crouch 要**连续离地超过 crouchGroundGrace** 才结束（默认 0.08s）。
  踩地判定偶尔会掉一两帧（接触刷新、碰撞体当帧刚改过高度），不留宽限的话人会被踢回站姿、
  下一帧又蹲下，看起来是每两帧抽一次。
- 头顶空间：MoveMotor.CanStandUp(站高, 蹲高) 从蹲姿头顶向上做圆形射线，扫到实体就继续蹲着；
  触发器（门、区域）与自身碰撞体都不算阻挡。站高由 View 的 Top/Bottom 量出（BodyHeight），
  蹲高 = 站高 × crouchHeightRatio。圆心会自动抬一个 radius，所以 headProbe.offset.y 填 0 时
  圆底正好贴蹲姿头顶、扫完落在站姿头顶；填负数等于把起扫点往下挪，最上面那截会漏检。
- 身高表现：改的是**碰撞体自己的 size/offset**，不是子物体的 transform.scale——
  非等比缩放一个胶囊会让形状退化（半径比半高还大），物理烘出来的形状与脚底位置都会漂，蹲下就抖。
  脚底由 offset 补回来，始终停在原地；竖直胶囊压到比自身还窄时，宽度跟着压到身高（形状必须合法）。
  墙探针的高度与中心同步跟随。
- View 缩放：逻辑层只给值（PlayerLogic.CurViewScale），PlayerController 以脚底为锚点落到 Transform 上。
  锚点在 Awake 初始化：`view = transform.Find("View")`、`bottom = view.Find("Bottom")`（都按名字找，不连线），
  缓存 View 的 localPosition / localScale，脚底距离 = `Bottom.localPosition.y × View.localScale.y`；
  缩放时 View 下移 (1−scale.y)×这段距离，脚才留在原地。
  基准必须是 local 值——存世界坐标再写回 localPosition，关卡根节点不在原点时人会被整体甩出去。
  注意 Bottom 是 View 的子节点，`transform.Find("Bottom")` 只扫一级子物体，永远找不到。

```
Crouch 改三样：身体高度（碰撞体 size/offset、墙探针）、移速（速度乘数）、可用动作（跳/冲）；
前摇只是把前两样从站姿值线性推到蹲姿值，限制仍按站姿给；
View 只是把身高倍率画出来，不参与任何判定。
```

## 十、地面判定与贴地

- 判据是"脚底"：MoveMotor 用 View 下的 Bottom（脚底）与 Top（头顶）两个参考点，
  地面探测、贴地、蹲起、头顶空间全部以它们为准；两个参考点没连线时按名字自动找，
  再找不到才退回用碰撞体底边/高度。
- 地面探测：从脚底上方 lift（默认 0.06）处放一个圆，向下扫 lift + distance。
  抬起这段是为了脚陷进地面时探针不从地面内部开始扫——那会直接扫空，人被误判成离地。
  扫到的距离减掉 lift 就是"脚底到地面的距离"，正=悬空，负=陷进去了。
- 只认法线朝上的面：倾角超过 maxSlopeAngle 的斜坡与竖直墙面不算地面。
- 贴地吸附：踩地且脚底与目标位置（地面 + groundSkin）的偏差**超过 snapDeadZone** 时才瞬移身体，
  一次修到位。没有死区时，物理求解器每帧留下的那点残余误差都会触发一次瞬移，
  位置一变接触就要重算，身体就会原地微抖。
- 踩地时竖直速度一律清零（见下一节）：求解器在接触恢复里塞进刚体的 +vy 不能被当成角色自己的上升速度。

## 十一、重力与速度钳制

- 踩地且 vy≤0：直接钳为 0，不累积重力。
- 踩地时竖直速度只由逻辑层写：物理引擎在接触恢复/边角顶起里塞进刚体的 vy 由表现层丢弃。
- 其余情况：vy 每帧减去当前重力 × Δt。
- 上升速度上限 maxRiseSpeed，下落速度下限 -maxFallSpeed。
- 重力来源：起跳写 riseGravity，顶点区间写 apexGravity。
- 重力来源：松键写 jumpCutGravity，跳跃结束写 fallGravity。
- moveAcceleration≤0 时，所有水平动作都当帧直达。

## 十二、参数速查

| 字段                | 作用       |
| ----------------- | -------- |
| moveSpeed         | 水平目标速度   |
| moveAcceleration  | 同向/起步加速度 |
| moveDeceleration  | 松键与待机减速度 |
| turnAcceleration  | 反向转身加速度  |
| jumpSpeed         | 地面跳初速度   |
| coyoteTime        | 离地起跳宽限   |
| maxAirJumps       | 空中跳次数    |
| airJumpSpeed      | 空中跳初速度   |
| dashSpeed         | 冲刺水平速度   |
| dashDuration      | 冲刺时长     |
| dashCooldown      | 冲刺冷却     |
| maxAirDashes      | 空中冲刺次数   |
| dashBufferTime    | 冲刺输入缓冲   |
| inputBufferTime   | 跳跃输入缓冲   |
| enableGravity     | 是否逻辑接管重力 |
| maxFallSpeed      | 下落速度上限   |
| maxRiseSpeed      | 上升速度上限   |
| fallGravity       | 下落段重力    |
| riseGravity       | 上升段重力    |
| apexThreshold     | 顶点区间阈值   |
| apexGravity       | 顶点区间重力   |
| jumpCutMultiplier | 松键速度截断系数 |
| jumpCutGravity    | 松键后重力    |
| crouchPrepareTime | 下蹲前摇时长（过渡状态用） |
| crouchHeightRatio | 下蹲身高倍率（身体/墙探针/View） |
| crouchMoveSpeedScale | 下蹲移速倍率（速度乘数） |
| crouchAllowJump   | 下蹲能否跳    |
| crouchAllowDash   | 下蹲能否冲    |
| crouchGroundGrace | 下蹲的离地宽限（防踩地抖动打断姿态） |

> 贴地吸附与探测是表现层（MoveMotor）的物理参数，不在 PlayerConfig 里：
> `snapToGround` 开关、`groundSkin` 吸附后脚底保留的间隙（默认 0.005，等于 Box2D 的 linear slop）、
> `snapDeadZone` 纠偏死区（默认 0.012）、`groundProbe.lift` 起扫高度（默认 0.06）、
> `groundProbe.distance` 脚底以下多深还算踩地（默认 0.08）。
